## 0. 三端一图

```
                    ┌─────────────────────────────────────┐
                    │  管理后台 /admin（React SPA，7 页）   │←── 管理员（口令+token）
                    └──────────────┬──────────────────────┘
                                   │ /api/admin/*
┌──────────────┐   /st/m、/st/f    │                        ┌──────────────┐
│ 对外展示端    │←─────────────────┤  pk-server (Rust:8787) │←─────────────│ 机器人        │
```

## 1. 系统功能总览（按能力域）

### 1.1 主播列表（主数据；2026-10-16 前叫「主播台账」，页面标题已改）
一人一行：**姓名唯一**，一人可挂多个抖音号（`account` 表，主号 `is_primary`）、一个手机号、师徒关系（`master_id`，支持多级族谱）、团别（男/女）、状态（active/left/paused）、榜单隐藏标记。姓名列显示抖音头像（本地留存，无图回落首字色块）；**手机号列只显示「有 / 没有」**（2026-10-16 口径：号码是敏感信息，列表只看登记状态，查看/修改走右键「编辑资料」）。
- 重复检测：同名分组提示「重名」，支持合并（主号/徒弟关系迁移）或改名
- 手机号登记（016 迁移）与**批量开号**：勾选台账主播 → 一键创建展示端登录账号（上限 500 人/次，支持 dryRun 预览、forceReset、CSPRNG 随机初始密码）
- 师徒关系批量导入、导入暂存区（未建档的历史导入行，建档后自动补账）

### 1.2 数据导入（音浪按日 / 时长与音浪按月）
- **按日**：文件上传或粘贴文本 → 预览校验 → 幂等提交。列序不严格，音浪单位（万/w）自动解析；**文件里有「开播有效时长 / 时长」列时按日写 `daily_metric.minutes`**（2026-10-19 用户口径：每日数据也带时长；预览弹窗出「当日时长」列、结果显示时长合计），没有该列的老文件不写时长、**保留库里已有值不清零**
- **按月**：整月导入一人一行，**时长 / 音浪可勾选（可同时导）**——时长写 `monthly_duration`、音浪写 `monthly_wave`；同月同指标重导「相同不覆盖、不同才覆盖」；展示端月 / 年优先用整月值、缺月回落日明细，累计与日口径不变
- 文件里**只有时长列、没有音浪列**才自动建议按月（`suggest.kind=month`）；时长 + 总音浪同表（概览列表）默认按日，运营在弹窗里手动切「按月」
- 团别按主播档案自动归属；同日重导按 merge 口径幂等
- 每次导入落 `import_batch` 批次审计；Excel/TSV/CSV 解析兜底；上传白名单（csv/tsv/txt/xlsx/xlsm/xls）、4MB 上限（超限 413）

### 1.3 PK 分组（核心算法，pk-core crate）
策略五种：**蛇形均衡**（S 型折返，默认）、**蛇形+同门回避**、**梯队·累计音浪**、**梯队·近 N 天**、**随机**。
内置硬约束**永远优先**：固定位（pinned）、互斥组（exclude_together）、最小间隔（min_gap）、最低组号（min_group）、强度位次（strength_order）。
配套：分组体检（inspect）、均衡微调（polish）、同门冲突局部交换、超编组再平衡、名单解析与人工名单保存、方案保存/发布/下架/导出长图、复活赛落位提示（第 ceil(组数/2) 组后，运营手动排）。

### 1.4 机器人与推送（QQ + 微信双通道）
- QQ：凭据保存、启动/停止、会话管理、命令限流
- 微信：iLink 网关全链路（扫码状态机 / baseurl 切换 / -14 暂停重试 / 媒体识别）、加好友二维码上传
- 推送：**每日报告**（图片版按 40 行分页 + 个人水印防转发 + 每日之星条）与**追分提醒**两套独立开关；追分目标上限 5 个（2026-10-15 起**按类独立**：追人 ≤5、目标分数 ≤5；追名次保留可列出 / 可删除，前端不再提供新增入口），支持「追人 + 自定义分数」与目标人**多选批量添加**；数据入库延迟推送队列、立即推送、失败记录、同业务日去重；每批 20 人间隔 3s
- 命令（用户，2026-10-18 起主命令是数字）：**`1` 每日榜单 / `2` 个人榜单 / `3` 徒弟榜单 / `4` 追分榜单** + 帮助 + 暂停 / 开启接收每日推送（旧名「每日报告 / 个人报告」保留为别名）；未绑定会话静默
- 命令（管理员）：状态 / 分组 / 总榜 / 排行 / 查询 / 导出 / 日报 / 缺数据 / 导入
- 每日报告追加「我的抖音号」明细段（≥2 个号才加，超 3 个折叠）

### 1.5 展示端账号与绑定
- **登录（2026-10-18 更新）**：手机号或艺名 + 密码（argon2id 存储，存量明文首次登录自动升级；密码 **4~64 字符、支持中英文/特殊字符/任意符号、不 trim**）。无账号的主播可**凭艺名直接认领开号**：登录失败返回 `canClaim` → 认领弹窗设密码 → `POST /api/public/my/claim {name, pass}` 建号（艺名在职唯一，迁移 041）。忘记密码 = 登录门 `POST /api/public/my/password/reset {phone, qq}`（双因子）→ 生成**临时密码发到已绑 QQ 邮箱**（15 分钟有效、**有效期内可重复登录、不单次消费**；登录后弹「请修改密码」提示层，可「稍后」）。未绑 QQ 的账号提示「请联系管理员重置」。⚠️ 知道手机号 + QQ 号即可触发重置，无短信通道，产品已确认保留，见 docs/24 §6
- **账号创建路径（2026-10-18 更新）**：① 管理员后台开号 —— 单条 `POST /api/admin/my-accounts`，或「主播台账 → 批量开号」`POST /api/admin/my-accounts/batch`；② 主播凭艺名自助认领（见上）。~~手机号自助注册（注册即绑定）~~ **已于 2026-10-14 彻底移除**：登录门「注册」页签 / OAuth 授权步骤 / 姓名核对全删，6 条 `/api/public/my/register*` 路由、WorkBuddy 网关模块 `wbgateway.rs`、`myRegister` 开关、注册链路的自检脚本（415 行）一并删除
- **QQ 邮箱（2026-10-18）**：`POST /api/public/my/email {qq}`（自动补 `@qq.com`；**同一 QQ 只能绑一个账号**，迁移 040；`{qq:""}` 解绑）→ `{ok, emailMask}`；管理端与展示端一律只显示脱敏 `emailMask`。QQ 绑定**不强制**，未绑时忘记密码只能找管理员
- **首次补全（2026-10-18）**：`POST /api/public/my/profile/bind`（`phone` 必填、`qq`/`newPass` 选填，单事务，成功后换发 token）
- **重置密码（个人页，已登录；2026-10-15 起不校验旧密码）**：`POST /api/public/my/password`（头 `X-My-Token`，体 `{"newPass"}`；带 `oldPass` 也忽略、不报错）→ `200 {"ok":true,"token":"<新 token>","mustChangePass":false}`（旧 token 全吊销 + 换发同身份新 token）；失败 400（密码需 4~64 字符（支持中英文/特殊字符/任意符号、不 trim）/ 该账号不支持自助改密）/ 401
- **绑定申请（已下线）**：~~未绑定账号登录后强制选台账姓名 → 生成申请单（pending）→ 管理端批准/驳回 → 通过后账号名改写为台账现名并回写 person_id 锚点、吊销旧 token~~ —— **该功能已于 2026-10-16 下线：导航与接口移除，表保留**（`my_bind_requests`）。账号 → 主播的绑定自 2026-10-14 起只由管理员在后台做
- **抖音号绑定审计（已下线）**：~~提交抖音号 + 主页截图 → 管理端看图裁决~~ —— **该功能已于 2026-10-16 下线：导航与接口移除，表保留**（`anchor_claims`）

### 1.6 展示设置与门禁
- 开关：男团/女团榜、月榜、年榜、师徒树、「我的」页、验证入口、每日之星称号（可配或手动指定）。~~手机号注册开关~~ 已于 2026-10-14 随注册功能删除
- IP 门禁：省级白名单（河南/安徽 + 江苏徐州）+ `ip_allowlist` 表 + `IP_GATE_ALLOWLIST` 环境变量三条例外通道；本地开发 `IP_GATE_DISABLED=1`；放行与拒绝都写访问日志（5 分钟桶去重）
- 公开 API 按下发口径过滤数据（个人字段显隐后台控制，读者侧本地记忆只是显示层）

### 1.7 运维与安全
- 健康检查（db/redis/writer/scheduler 四态）、访客日志后台、IP 现场查询、Geo 缓存 7 天
- 数据库迁移器（`pk-server migrate`，版本登记 001→019），DDL 不随启动自动跑
- 管理员口令：`ADMIN_PASSWORD` 环境变量优先，未配置时默认 `shuai4444`（`auth::DEFAULT_ADMIN_PASSWORD`，2026-10-19 用户口径，旧的 fail-closed 拒绝启动已作废）；登录失败 5 次锁 10 分钟（限流按 XFF 最后一跳，不可伪造）
- SSE 事件通道：数据变更后管理页自动刷新（内存广播，非持久化）

## 2. 管理后台页面（/admin，React SPA，7 页）

登录：`/admin` → 输入管理员口令换 token（8h 有效），全部 `/api/admin/*` 需带 Bearer。

### 2.1 数据概况（/admin/data · DashboardPage）
首屏聚合。左右双栏：
- **音浪 Top 10**（当日/近 N 日口径切换）｜**未播预警（连续 ≥2 天）**——紧凑卡片，条目超 240px 内部滚动、表头吸顶
- **团别音浪趋势**（近 N 天折线）
- 头部：在册规模、最近业务日期、延迟推送状态、写库连接状态
- 顶部工具：天数切换、强制刷新缓存

### 2.2 数据导入（/admin/import · ImportPage）
- 上传/粘贴 → 预览（逐行校验结果、错误行标注）→ 提交 → 批次记录列表（来源/文件/业务日/行数/成败/备注）
- 按日与按月两种类型，切换即换解析器；按月弹窗可选「时长 / 音浪」（可同时勾选，勾哪个写哪个），预览显示该月已导入的整月时长 / 音浪与日明细对账（`waveDiffs`）
- 历史批次可查可管，当日状态一目了然

### 2.3 主播管理（/admin/streamers · StreamerPage）
最大页面。能力：
- 查询/分页/新增/编辑/删除/批量删除；重名标记与合并
- **姓名列头像（2026-10-16 二期）**：32px 圆形抖音头像（`/api/admin/streamers` item 新增 `hasAvatar` / `avatarHash`；取图走同源 `GET /api/public/avatars/{personId}?v={hash}`），无图回落姓名首字色块、不裂图；页内**同步按钮**调 `POST /api/admin/avatars/sync` 手动同步（默认只抓无图或超 7 天的人；定时器自动刷新默认已关，见 docs/25 §12）
- 明细抽屉：基本档案 + 抖音号列表（增删、主号切换）+ 手机号（格式校验、双侧查重）+ 师徒关系 + 展示端账号（密码重置/解绑/改绑）
- 批量开号向导（勾选 → 预览 → 执行，逐条结果表，初始密码列表供抄送主播）
- 师徒关系批量导入、导入暂存区、重复主播检测入口
- 手机号批量开展示端账号（详见 1.1）

### 2.5 访客日志（/admin/visits · VisitPage）
- 访问记录流水：时间/IP/归属地（省市区+运营商+数据源）/团别/路径/账号/是否放行/是否登录成功；关键字搜索
- **访问白名单管理**：增删 IP（精确/CIDR）；白名单 = 地区规则之外的额外放行
- IP 现场查询（诊断单个 IP 的判定结果与数据源）

### 2.6 族谱（/admin/lineage · LineagePage + LineageCanvas）
师徒树可视化：卡片树多级嵌套、搜索高亮、展开收起、祖师视角指标卡、拖拽画布。管理员看全组树。

### 2.7 PK 分组（/admin/group · GroupPage）
分组工作台（功能最重的一页）：
- 名单来源：粘贴解析 / 历史名单 / 台账候选；别名自动映射
- 策略选择（五种，梯队策略强制联动音浪口径）+ 约束编辑（固定位/互斥/间隔/最低组号/强度位次，内置条件优先）
- 结果画布：**原生指针拖拽**调人 + 键盘微调、锁定名单、临时加人、分组体检与微调按钮
- 赛制切换（初级/中级/晋级/月终）、标题配置、晋级与复活规则展示（REVIVAL 规则内建）
- 方案保存/历史/删除/**发布**（发布后展示端立即可见）/导出 PNG 长图/**导出总排名分差图**（总排名 + 相邻名次分差 + 前10/前5/前三/前2/前1 五档门槛差 + 各组名次区间，单独 PNG）

### 2.8 机器人（/admin/bots · BotPage）
- QQ：凭据（appId/secret）保存、启动/停止、状态灯
- 微信：启动/停止、扫码二维码弹窗、扫码状态轮询、加好友二维码上传
- 会话列表（谁在用机器人）
- **展示端账号管理**：我的页面账号列表（手机号/密码重置/绑定主播/改绑/删除）+ 批量开号入口；**2026-10-18 起列表新增 QQ 绑定状态列（只显示脱敏 `emailMask`，未绑显示「未绑定」）与「待改密」标记**，主播端账号弹窗同样只显示脱敏值、不显示明文 QQ/邮箱。这是管理员开号主入口，另加主播自助「艺名认领」（自助注册仍已于 2026-10-14 移除）
- **公开站点设置**：男团/女团/月榜/年榜/师徒树/我的页等全部开关 + 每日之星称号 + 推送任务队列查看（~~注册开关~~ 已于 2026-10-14 删除）

## 3. 对外展示端页面（/st/m、/st/f，后端托管单页，移动端优先）

登录门：开启登录要求的站点，未登录时整页被登录卡盖住——**只剩「登录」页签**（~~「注册」页签~~ 已于 2026-10-14 随注册功能删除）、**手机号或艺名 + 密码**（密码 4~64 字符任意字符、不 trim）、忘记密码（**手机号 + QQ 号双因子 → 临时密码发 QQ 邮箱**；未绑 QQ 提示找管理员）、错误红字行；登录失败且 `canClaim` 时显示**「认领账号」**入口（2026-10-18）。管理员可用「账号=密码=管理口令」直接进（观看身份）。

**公告触达（2026-10-15）**：展示页公告条（后台「公告页 → 📣 展示页公告条」配置的 items）支持**横幅 + 弹窗**两种形态——每条新增「弹窗提醒」开关（`AnnounceItem.popup`，旧数据缺省 false）；开启后该条除顶部横幅外在展示端以弹窗形式弹出一次（点「知道了」/空白处关闭，按 announcement version 记已读，下次保存版本前进再弹）；横幅与弹窗互不排斥。弹窗正文支持 *加粗* 与行首 `·`/`1.` 列表（白名单富文本，全程转义防注入）。**横幅对齐（2026-10-16）**：每条新增 `AnnounceItem.align`（`left`（默认）/`center`/`right`，空 / 非法 / 大小写不符一律归一 `left` —— 老数据没有该字段即原版式）；展示端渲染成 `ai-left/ai-center/ai-right`，居中/居右时把「图标 + 文案」作为一整组靠中/靠右（left 仍是原版式：图标靠左、正文撑满）；后台在每条公告条目上用三个对齐图标（`format_align_left/center/right`）即点即存，与「样式/图标」下拉同一保存口径。只影响横幅，弹窗不动。
