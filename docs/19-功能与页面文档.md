## 0. 三端一图

```
                    ┌─────────────────────────────────────┐
                    │  管理后台 /admin（React SPA，8 页）   │←── 管理员（口令+token）
                    └──────────────┬──────────────────────┘
                                   │ /api/admin/*
┌──────────────┐   /st/m、/st/f    │                        ┌──────────────┐
│ 对外展示端    │←─────────────────┤  pk-server (Rust:8787) │←─────────────│ 机器人        │
│ 主播/粉丝手机 │   /api/public/*  │  PostgreSQL 3318 唯一库 │  QQ/微信协议  │ 主播+运营     │
└──────────────┘                  └────────────────────────┘              └──────────────┘
        ↑ IP 地域门禁（访问日志照记）        ↑ 只读池(pk_reader)/写池(douyin_writer)分权
```

- **管理后台**：运营自用，管理全部数据与开关
- **对外展示端**：主播和粉丝用手机看，含"我的"个人页
- **机器人**：QQ + 微信双通道，主播在聊天里拿报告/管推送

## 1. 系统功能总览（按能力域）

### 1.1 主播台账（主数据）
一人一行：**姓名唯一**，一人可挂多个抖音号（`account` 表，主号 `is_primary`）、一个手机号、师徒关系（`master_id`，支持多级族谱）、团别（男/女）、状态（active/left/paused）、榜单隐藏标记。
- 重复检测：同名分组提示「重名」，支持合并（主号/徒弟关系迁移）或改名
- 手机号登记（016 迁移）与**批量开号**：勾选台账主播 → 一键创建展示端登录账号（上限 500 人/次，支持 dryRun 预览、forceReset、CSPRNG 随机初始密码）
- 师徒关系批量导入、导入暂存区（未建档的历史导入行，建档后自动补账）

### 1.2 数据导入（音浪按日 / 时长按月）
- **音浪（按日）**：文件上传或粘贴文本 → 预览校验 → 幂等提交。列序不严格，音浪单位（万/w）自动解析；文件里的时长列忽略
- **时长（按月）**：整月导入一人一行，写 `monthly_duration`；同月重导「相同不覆盖、不同才覆盖」
- 团别按主播档案自动归属；同日重导按 merge 口径幂等
- 每次导入落 `import_batch` 批次审计；Excel/TSV/CSV 解析兜底；上传白名单（csv/tsv/txt/xlsx/xlsm/xls）、4MB 上限（超限 413）

### 1.3 PK 分组（核心算法，pk-core crate）
策略五种：**蛇形均衡**（S 型折返，默认）、**蛇形+同门回避**、**梯队·累计音浪**、**梯队·近 N 天**、**随机**。
内置硬约束**永远优先**：固定位（pinned）、互斥组（exclude_together）、最小间隔（min_gap）、最低组号（min_group）、强度位次（strength_order）。
配套：分组体检（inspect）、均衡微调（polish）、同门冲突局部交换、超编组再平衡、名单解析与人工名单保存、方案保存/发布/下架/导出长图、复活赛落位提示（第 ceil(组数/2) 组后，运营手动排）。

### 1.4 机器人与推送（QQ + 微信双通道）
- QQ：凭据保存、启动/停止、会话管理、命令限流
- 微信：iLink 网关全链路（扫码状态机 / baseurl 切换 / -14 暂停重试 / 媒体识别）、加好友二维码上传
- 推送：**每日报告**（图片版按 40 行分页 + 个人水印防转发 + 每日之星条）与**追分提醒**两套独立开关；追分目标上限 5 个（2026-10-15 起**按类独立**：追人 ≤5、目标分数 ≤5；追名次保留可列出 / 可删除，前端不再提供新增入口），支持「追人 + 自定义分数」与目标人**多选批量添加**；数据入库延迟推送队列、立即推送、失败记录、同业务日去重；每批 20 人间隔 3s
- 命令（用户）：帮助 / 每日报告 / 个人报告 / 暂停接收每日推送 / 开启接收每日推送；未绑定会话静默
- 命令（管理员）：状态 / 分组 / 总榜 / 排行 / 查询 / 导出 / 日报 / 缺数据 / 导入
- 每日报告追加「我的抖音号」明细段（≥2 个号才加，超 3 个折叠）

### 1.5 展示端账号与绑定
- **登录**：手机号或姓名 + 密码（argon2id 存储，存量明文首次登录自动升级）；忘记密码 = 登录门 `POST /api/public/my/password/reset {phone}` → 重置为**随机临时密码**并在响应里下发一次（**不再是手机号后四位**；⚠️ 知道手机号即可重置，无短信通道，产品已确认保留，见 docs/24 §6）
- **账号创建（唯一路径）**：管理员后台开号 —— 单条 `POST /api/admin/my-accounts`，或「主播台账 → 批量开号」`POST /api/admin/my-accounts/batch`。~~手机号自助注册（注册即绑定）~~ **已于 2026-10-14 彻底移除**：登录门「注册」页签 / OAuth 授权步骤 / 姓名核对全删，6 条 `/api/public/my/register*` 路由、WorkBuddy 网关模块 `wbgateway.rs`、`myRegister` 开关、注册链路的自检脚本（415 行）一并删除
- **重置密码（个人页，已登录；2026-10-15 起不校验旧密码）**：`POST /api/public/my/password`（头 `X-My-Token`，体 `{"newPass"}`；带 `oldPass` 也忽略、不报错）→ `200 {"ok":true,"token":"<新 token>"}`（旧 token 全吊销 + 换发同身份新 token）；失败 400（密码必须 4~20 位字母或数字 / 该账号不支持自助改密）/ 401
- **绑定申请**：未绑定账号登录后强制选台账姓名 → 生成申请单（pending）→ 管理端批准/驳回 → 通过后账号名改写为台账现名并回写 person_id 锚点、吊销旧 token
- **抖音号绑定审计**：提交抖音号 + 主页截图 → 管理端看图裁决

### 1.6 展示设置与门禁
- 开关：男团/女团榜、月榜、年榜、师徒树、「我的」页、验证入口、每日之星称号（可配或手动指定）。~~手机号注册开关~~ 已于 2026-10-14 随注册功能删除
- IP 门禁：省级白名单（河南/安徽 + 江苏徐州）+ `ip_allowlist` 表 + `IP_GATE_ALLOWLIST` 环境变量三条例外通道；本地开发 `IP_GATE_DISABLED=1`；放行与拒绝都写访问日志（5 分钟桶去重）
- 公开 API 按下发口径过滤数据（个人字段显隐后台控制，读者侧本地记忆只是显示层）

### 1.7 运维与安全
- 健康检查（db/redis/writer/scheduler 四态）、访客日志后台、IP 现场查询、Geo 缓存 7 天
- 数据库迁移器（`pk-server migrate`，版本登记 001→019），DDL 不随启动自动跑
- 管理员 fail-closed：无 ADMIN_PASSWORD 拒绝启动；登录失败 5 次锁 10 分钟（限流按 XFF 最后一跳，不可伪造）
- SSE 事件通道：数据变更后管理页自动刷新（内存广播，非持久化）

## 2. 管理后台页面（/admin，React SPA，8 页）

登录：`/admin` → 输入管理员口令换 token（8h 有效），全部 `/api/admin/*` 需带 Bearer。

### 2.1 数据概况（/admin/data · DashboardPage）
首屏聚合。左右双栏：
- **音浪 Top 10**（当日/近 N 日口径切换）｜**未播预警（连续 ≥2 天）**——紧凑卡片，条目超 240px 内部滚动、表头吸顶
- **团别音浪趋势**（近 N 天折线）
- 头部：在册规模、最近业务日期、延迟推送状态、写库连接状态
- 顶部工具：天数切换、强制刷新缓存

### 2.2 数据导入（/admin/import · ImportPage）
- 上传/粘贴 → 预览（逐行校验结果、错误行标注）→ 提交 → 批次记录列表（来源/文件/业务日/行数/成败/备注）
- 音浪按日与时长按月两种类型，切换即换解析器
- 历史批次可查可管，当日状态一目了然

### 2.3 主播管理（/admin/streamers · StreamerPage）
最大页面。能力：
- 查询/分页/新增/编辑/删除/批量删除；重名标记与合并
- 明细抽屉：基本档案 + 抖音号列表（增删、主号切换）+ 手机号（格式校验、双侧查重）+ 师徒关系 + 展示端账号（密码重置/解绑/改绑）
- 批量开号向导（勾选 → 预览 → 执行，逐条结果表，初始密码列表供抄送主播）
- 师徒关系批量导入、导入暂存区、重复主播检测入口
- 手机号批量开展示端账号（详见 1.1）

### 2.4 抖音号审计（/admin/claims · ClaimPage）
展示端用户提交的「抖音号 + 主页截图」审核台：列表按状态筛选 → 看大图 → 通过/拒绝（拒绝填原因回显给用户）。通过后自动更新主播档案的抖音号。

### 2.5 访客日志（/admin/visits · VisitPage）
- 访问记录流水：时间/IP/归属地（省市区+运营商+数据源）/团别/路径/账号/是否放行/是否登录成功；关键字搜索
- **访问白名单管理**：增删 IP（精确/CIDR）；白名单 = 地区规则之外的额外放行
- IP 现场查询（诊断单个 IP 的判定结果与数据源）

### 2.6 族谱（/admin/lineage · LineagePage + LineageCanvas）
师徒树可视化：卡片树多级嵌套、搜索高亮、展开收起、祖师视角指标卡、拖拽画布。管理员看全组树。

### 2.7 PK 分组（/admin/group · GroupPage）
分组工作台（功能最重的一页）：
- 名单来源：粘贴解析 / 历史名单 / 台账候选；别名自动映射
- 策略选择（五种，梯队策略强制联动音浪口径）+ 约束编辑（固定位/互斥/间隔/最低组号/强度位次，内置条件优先）
- 结果画布：**原生指针拖拽**调人 + 键盘微调、锁定名单、临时加人、分组体检与微调按钮
- 赛制切换（初级/中级/晋级/月终）、标题配置、晋级与复活规则展示（REVIVAL 规则内建）
- 方案保存/历史/删除/**发布**（发布后展示端立即可见）/导出 PNG 长图

### 2.8 机器人（/admin/bots · BotPage）
- QQ：凭据（appId/secret）保存、启动/停止、状态灯
- 微信：启动/停止、扫码二维码弹窗、扫码状态轮询、加好友二维码上传
- 会话列表（谁在用机器人）
- **展示端账号管理**：我的页面账号列表（手机号/密码重置/绑定主播/改绑/删除）+ 批量开号入口 —— **这是展示端账号的唯一创建路径**（自助注册已于 2026-10-14 移除）
- **公开站点设置**：男团/女团/月榜/年榜/师徒树/我的页等全部开关 + 每日之星称号 + 推送任务队列查看（~~注册开关~~ 已于 2026-10-14 删除）

## 3. 对外展示端页面（/st/m、/st/f，后端托管单页，移动端优先）

登录门：开启登录要求的站点，未登录时整页被登录卡盖住——**只剩「登录」页签**（~~「注册」页签~~ 已于 2026-10-14 随注册功能删除）、手机号或姓名 + 密码、忘记密码（重置为**随机临时密码**，不再是手机号后四位）、错误红字行。管理员可用「账号=密码=管理口令」直接进（观看身份）。

底部四页签：

### 3.1 数据榜（首页 · view=data）
- 男团/女团（URL 即团别：`/st/m`、`/st/f`），主播数据榜：当日/近 N 日/月榜/年榜口径、累计音浪、开播状态（未播灰显）、等级、涨跌红绿
- 字段显隐（读者本地记忆）、自动静默刷新、搜索
- 地区门禁外的 IP 看到「您的 ip 不在授权范围内」

### 3.2 分组（view=group）
已发布的 PK 分组方案，按赛事类型五个子页：初级争霸赛小组赛 / 中级争霸赛小组赛 / 月终争霸赛 / 初级晋级赛 / 中级晋级赛。展示时段分组、休息位、标题；晋级与复活赛规则卡（未写规则的赛事不显示）。

### 3.3 族谱（view=lineage）
师徒树公开版：卡片树嵌套、搜索 dim/高亮、全部展开/收起。**音浪口径只显示自己徒弟的**（日/月/年三口径），无徒弟显示「暂未收徒」；管理员登录则看全组树。

### 3.4 我的（view=my，需登录）
- **同期对照**：今日 vs 上一业务日 / 本月 vs 上月 / 本年 vs 去年同期（涨红跌绿）
- **我的抖音号**卡：一行一号的日/月/年/累计音浪 + 合计行（主号走 daily_metric，副号走 wave_snapshot）
- **战队排名**只显示自己的名次（不暴露团队规模与名次差，防反推）
- **消息设置**子页（2026-10-15，由原「推送机器人服务」改名；`/my/wechat`，`/my/push` 为兼容别名，旧链接仍打开同一页）——三段：① 微信对接（扫码绑定 / 轮询、绑定码、解绑、绑定状态三态）② 推送开关（追分提醒 / 每日报告 / 师门日报，师门日报仅名下有直系徒弟时显示；`lineageReport` 不传 = 不改动现值）③ **追分设置**入口（一行，跳 `/my/chase` 子页）
- **追分设置**子页（`/my/chase`）：「目标分数」≤5、「目标人」≤5（各自独立计数；目标人支持本团搜索 + 多选批量添加）、「名次目标」只读可删，添加按钮在已满时置灰显示「最多 5 个」
- **绑定主播**子页（未绑定时强制进入）：搜台账姓名 → 提交 → 等管理端审核
- **抖音号认领**子页：提交抖音号 + 截图 → 等审计
- **重置密码**（2026-10-14 上线，2026-10-15 起不再要求旧密码）：对话框只有 新密码 / 确认新密码（两次不一致前端拦下、不发请求）→ `POST /api/public/my/password`；成功后旧登录态全吊销并换发新 token。**已登录场景不再走手机号重置**
- 隐私说明 / 关于 子页；全屏手机号水印（防截屏外传）
