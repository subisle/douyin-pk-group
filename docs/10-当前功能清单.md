# 当前功能清单

> 生成时间：2026-10-11。本文不是新需求文档，只按当前仓库代码和 `docs/00` 的架构基线，输出已经存在的功能与尚未挂 UI 的能力。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 已上线 | 后端接口、前端页面和调用链都存在；是否完成生产实测另看说明 |
| 后端已实现 | 服务端已有能力，当前管理界面或对外展示页未直接使用 |
| 部署开关 | 代码已实现，默认或部署环境可控制开关 |
| 过渡实现 | 代码仍存在，但架构基线标记为退役或迁移对象 |

## 1. 运行形态

- **已上线**：Rust `pk-server` 是当前主服务，`axum` 提供公开 API、管理 API、SSE、静态 SPA 和机器人适配。
- **已上线**：MariaDB/MYSQL 业务库承载主播、账号、日/月指标、导入批次、方案、机器人绑定、推送任务和审计数据；迁移器统一建表。
- **已上线**：React + Vite SPA `apps/douyin-web`，包含后台与对外展示；构建产物由 `pk-server` 托管。
- **已收敛（2026-10）**：旧管理 SPA `apps/web`、`packages/shared`、Go 过渡服务 `server-go`
  均已删除（含 CI Go job、Go 镜像、compose 里的 `douyin-server` 条目）。
  前端只有 `apps/douyin-web` 一套，后端只有 Rust `pk-server` 一个常驻服务。
- **部署开关**：RK3318 Docker Compose 提供 MariaDB、migrator、pk-server、只读账号初始化和镜像构建；另一套 `deploy/docker-compose.yml` 提供通用部署编排。

## 2. 管理后台

### 2.1 认证与会话

- **已上线**：管理员登录、登出、会话查询；未登录访问管理 API 会被拦截。
- **已上线**：SSE 事件通道，管理页在数据变更或导入完成后自动刷新。

### 2.2 数据概况

- **已上线**：聚合数据概况、在册规模、最近业务日期、延迟状态和写库连接状态。
- **已上线**：每日报告 SVG 图片预览。

### 2.3 主播台账

- **已上线**：主播查询、分页浏览、新增、修改、删除和批量删除。
- **已上线**：维护姓名、团别、抖音号、别名、师徒关系、参赛状态、隐藏状态等档案字段。
- **已上线**：重复主播检测、师徒树/传承关系图展示、师徒关系批量导入。
- **已上线**：导入暂存区查看、删除；建档后自动补账未落表的历史导入行。

### 2.4 数据导入

- **已上线**：文件上传与粘贴文本导入。
- **已上线**：按日音浪/时长指标的上传、预览、校验、幂等提交、批次记录、当日状态、整日删除。
- **已上线**：月度时长整月导入、预览、校验、提交、状态、删除；平台月报口径写入 `monthly_duration`。
- **已上线**：按主播档案自动归属团别；同一天重复导入时按 merge 口径幂等处理。
- **已上线**：Excel/TSV/CSV 解析兜底，包括音浪单位解析。

### 2.5 PK 分组

- **已上线**：名单解析、人工名单保存、主播候选读取、别名管理。
- **已上线**：自动分组，策略包括 snake、balance、sequential、sequential last N，支持名单自带分数。
- **已上线**：固定位、互斥、最小间隔、组次等硬约束优先满足。
- **已上线**：分组体检、均衡微调、强度位次微调、未匹配/排除名单处理。
- **已上线**：原生指针拖拽和键盘微调、锁定名单、临时添加选手。
- **已上线**：方案保存、历史方案查询、删除、发布/下架。
- **已上线**：按数据口径重新计算、刷新缓存、导出长图。
- **已上线**：晋级赛、常规则、男团/女团等赛制切换与标题配置。

### 2.6 机器人与推送

- **已上线**：QQ 机器人凭据保存、启动/停止、状态查询。
- **已上线**：微信机器人启动/停止、扫码二维码、扫码状态轮询、Token 更新。
- **已上线**：微信加好友二维码上传，展示端“我的”页读取。
- **已上线**：机器人会话查询、管理员绑定、命令限流。
- **已上线**：普通用户命令：每日报告、个人报告、暂停/开启每日推送、帮助；未绑定会话静默。
- **已上线**：管理员命令：分组、排行、查询、导出、日报、缺数据、文本/附件导入、日期黏连等。
- **已上线**：按 `push_bindings` 生成绑定码，展示端与机器人共用手机号绑定状态。
- **已上线**：每日报告与追分提醒两套独立开关，追分目标最多 5 个。
- **已上线**：数据入库延迟推送队列、立即推送、失败原因记录和同一业务日去重。

### 2.7 我的账号与绑定审计

- **后端已实现**：展示端手机号自助注册（注册时填主播姓名并校验台账，**注册即绑定**）、WorkBuddy OAuth 添加账号、注册状态轮询、取消注册；默认关闭，由后台展示设置控制。
- **已上线**：展示端绑定申请：提交抖音号与截图、查询申请状态；后台审核、通过、拒绝、撤销，并在通过后更新主播档案。
- **已上线**：后台维护“我的页面账号”手机号、绑定状态和来源。

### 2.8 展示设置

- **后端已实现**：男团/女团数据榜、月榜、年榜、师徒树、“我的”页、验证入口、手机号注册、默认日期等展示口径开关。
- **后端已实现**：个人数据字段显隐控制；公开接口按下发口径过滤数据。
- **已上线（1.0.1）**：徒弟提成设置（机器人页）：折算比例（音浪:人民币，默认 10:1）+ 排除名单（鹏先生等不参与统计的师傅）+ 提成显示开关；后台改完即时生效、不追溯。
- **说明**：当前主后台的机器人页承载部分展示设置维护；独立 `/admin/settings` 页尚未出现在主 SPA 路由。

## 3. 对外展示

- **已上线**：移动端展示页根路由 `/`，兼容 `/1`、`/0`、`/st/m`、`/st/f`、`/report`、`/lineage`、`/my` 和 `/group/*`。
- **已上线**：男团/女团数据榜，支持当日、近 N 日、月榜、年榜、开播状态、等级、涨跌和自动静默刷新。
- **已上线**：读者侧字段显隐本地记忆；公开 API 仍以后端开关为最终边界。
- **已上线**：已发布 PK 分组方案展示，按时段分组、休息位和标题渲染。
- **已上线**：师徒树/传承关系公开展示。
- **已上线（1.0.1）**：“我的”页同期对照（今日 vs 上一业务日 / 本月 vs 上月 / 本年 vs 去年同期，涨红跌绿）。
- **已上线（1.0.1）**：“我的”页徒弟提成卡（仅直系徒弟、徒孙不计；比例与排除名单见 §2.8）。
- **已上线（1.0.1）**：微信 iLink 网关全链路对齐 Tencent/openclaw-weixin 协议（扫码状态机 / baseurl 切换 / -14 暂停重试 / 媒体识别）；推送分批（每批 20 人、间隔 3s，env 可调）。
- **已上线**：公开申请绑定主播：手机号验证、抖音号、截图上传、状态查询；后台审核闭环。
- **部署开关**：数据 API 由河南/安徽地域门禁控制，放行与拒绝都写访问日志。

## 4. 数据域与算法

- **已上线**：人员与账号主数据，一人可多账号/抖音号。
- **已上线**：日指标 `daily_metric`，包含音浪、累计值、直播状态、时长、来源批次和可靠性。
- **已上线**：月度指标、月度时长、波快照与时长快照。
- **已上线**：导入批次审计、暂存导入、配置、别名、方案、名单状态。
- **已上线**：未开播阈值判定、隐藏主播过滤、业务日期口径、近 N 天聚合。
- **已上线**：分组算法集中在 `pk-core`，浏览器不运行第二份权威实现。

- **已上线**：访客 IP 地域判定、缓存、门禁中间件、访问日志。
- **已上线**：后台访客日志、IP 现场检查、外省拦截。
- **已上线**：数据库迁移器、schema migration 记录和 Docker 初始化脚本。
- **已上线**：Grafana/Prometheus 指标采集代码。
- **已上线**：QQ/微信机器人会话限流和统一错误文案。

## 6. 架构基线中的已知边界

- 徒弟提成只聚合 `daily_metric`（主号口径），**副号** `wave_snapshot` 音浪不计入提成（与个人卡口径一致）；提成不落账、不追溯，改比例按当前比例现算。
- 微信 -14 登录过期先暂停 1 小时自动重试（不清凭据），连续 4 次仍过期才要求重扫；扫码 `need_verifycode` / `scaned_but_redirect` 已支持。
- 媒体出站（getuploadurl / AES 加密上传）能力就位但推送本期仍纯文本；sendtyping 输入状态未实现。

- 机器人 QQ/微信渠道凭据和主动推送仍需生产实测；微信主动推送依赖最后一次私聊留下的 `context_token`。
- 手机号注册默认关闭；启用前需要先验证 WorkBuddy 网关配置。
- 独立后台设置页尚未在主 SPA 中落地，展示口径目前分散在机器人页相关接口维护。
- 当前本地业务库只剩 4 条 `daily_metric` 记录；旧音浪历史主要保存在
  `.local-assets/sqlite-archive/`（已移出 git）与 `data/backups/` 的 SQL 备份
  （按业务日期标记覆盖 2026-05-01 至 2026-10-06；`data/` 为 gitignore 的现场目录）。
