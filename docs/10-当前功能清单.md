# 当前功能清单

> 生成时间：2026-10-11。本文不是新需求文档，只按当前仓库代码和 `docs/00` 的架构基线，输出已经存在的功能与尚未挂 UI 的能力。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 已上线 | 后端接口、前端页面和调用链都存在；是否完成生产实测另看说明 |
| 后端已实现 | 服务端已有能力，当前管理界面或对外展示页未直接使用 |
| 部署开关 | 代码已实现，默认或部署环境可控制开关 |
| 过渡实现 | 代码仍存在，但架构基线标记为退役或迁移对象 |

## 1. 运行形态

- **已上线**：Rust `pk-server` 是当前主服务，`axum` 提供公开 API、管理 API、SSE、静态 SPA 和机器人适配。
- **已上线**：MariaDB/MYSQL 业务库承载主播、账号、日/月指标、导入批次、方案、机器人绑定、推送任务和审计数据；迁移器统一建表。
- **已上线**：React + Vite SPA `apps/douyin-web`，包含后台与对外展示；构建产物由 `pk-server` 托管。
- **已收敛（2026-10）**：旧管理 SPA `apps/web`、`packages/shared`、Go 过渡服务 `server-go`
  均已删除（含 CI Go job、Go 镜像、compose 里的 `douyin-server` 条目）。
  前端只有 `apps/douyin-web` 一套，后端只有 Rust `pk-server` 一个常驻服务。
- **部署开关**：RK3318（arm64 Docker）与 147（amd64 systemd）同为现役生产，一键脚本分别为 `scripts/deploy-rk3318.sh` 与 `scripts/deploy/147.sh`；RK3318 Docker Compose 提供 MariaDB、migrator、pk-server、只读账号初始化和镜像构建，另一套 `deploy/docker-compose.yml` 提供通用部署编排。

## 2. 管理后台

- **已上线**：管理员登录、登出、会话查询；未登录访问管理 API 会被拦截。
- **已上线**：SSE 事件通道，管理页在数据变更或导入完成后自动刷新。

### 2.2 数据概况

- **已上线**：聚合数据概况、在册规模、最近业务日期、延迟状态和写库连接状态。
- **已上线**：每日报告 SVG 图片预览。

- **已上线**：维护姓名、团别、抖音号、别名、师徒关系、参赛状态、隐藏状态等档案字段。

- **已上线**：导入暂存区查看、删除；建档后自动补账未落表的历史导入行。
