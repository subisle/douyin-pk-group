## 1. 需求理解与范围

### 1.1 用户原话

> 「准备做一下这个漂浮的弹幕效果。为每日之星前三名的」
> 「弹幕使用电视那种弹幕透明度低，慢的那种文字透明一点，不能点击的。点击也不影响动。」
> 「可以多一点，每日之星不要，文字为 今日第一名：第二名，第三名。这样数量可以多一点。」

落成规格：

- **「每日之星前三名」= 当日榜（每日之星榜）的第一、二、三名**，即页面上领奖台的冠军/亚军/季军三个人。
- **「电视那种弹幕」= 纯文字、半透明、慢速、无交互**：
  - 不做胶囊/气泡/卡片，不做头像；
  - 文字整体半透明，从内容上慢慢飘过；
  - 不能点击，点击穿透、点击也不暂停/不重置动画。
- **「漂浮」= 缓慢横向漂移 + 轻微上下浮动**。

### 1.2 本期做 / 不做

| 做 | 不做 |
| --- | --- |
| 展示端数据看板每日口径的电视弹幕浮层 | 视频/直播弹幕、评论、发送弹幕输入框 |
| 前三名的「名次 + 艺名」（默认不带音浪，后台可开） | 头像、胶囊底、卡片、边框、「每日之星」标签 |
| 后台开关 + 速度/透明度/间隔/范围/**每轮条数** | 用户自定义颜色/字体/皮肤 |
| 与选中日期联动（切日期跟着换人） | 服务端推送/实时弹幕（WebSocket） |
| 降级、`prefers-reduced-motion`、性能暂停 | 单独的管理端预览页面（可后续加） |
| 不可点击、点击不影响动画 | 弹幕暂停/选中等交互 |

### 1.3 非目标

- 不改 `/daily` 接口的既有字段与语义。
- 不改推送/日报图里的「🚩 每日之星」口径（那套仍是**单星**，见 §4.2）。
- 不引入任何外网资源（奖杯图沿用页面里已内嵌的 base64）。

## 3. 总体方案

### 3.1 数据流

```
GET /api/public/teams/{team}                GET /api/public/teams/{team}/daily?date=
        │  starDanmaku 配置                        │  items（含 rank/wave）
        ▼                                          ▼
   site.starDanmaku ────────────────►  starDm.refresh()
                                            │  1) enabled? 2) view==='data'? 3) period==='daily'?
                                            │  4) reduced-motion? 5) 有 1~3 名？
                                            ▼
                                   取 rank=1/2/3 各第一个人（与 podHtml 同口径）
                                            │  内容签名变了才重启
                                            ▼
                     量一次领奖台底边 → #starDm 放在其下方（不遮前三名）
                                            │
                            每轮生成 3 条纯文字弹幕（错峰 1.6s）
                                            │
                           CSS 右→左慢速漂移 + ±2px 上下浮动
                                            │
                                   mode=loop → 等 intervalSec 再来一轮
                                   mode=once → 本页生命周期只跑一轮
```

### 3.2 关键设计决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 数据来源 | 复用 `/daily` 的 `items` | ① 零新增请求/接口；② 与同页领奖台、榜单**必然一致**；③ 后台「音浪显隐」开关天然生效；④ 已排除已删/离团/隐藏的人 |
| 视觉形态 | **电视弹幕（纯文字）** | 用户口径；没有胶囊/头像更轻、不挡内容；电视弹幕的经典观感 |
| 文案 | 固定 **「今日第X名：名字」**（X = 一/二/三） | 用户口径；比「每日之星」标签更直白，且三条文案结构一致 |
| 数量 | **每轮 6 条**（三个名次各 2 条，循环铺开），可调 3~12 | 「这样数量可以多一点」；短文案适合多铺几条 |
| 车道 | **6 条**，在「领奖台下方 → tabbar 上方」之间等分 | 「位置可以再多一点」：竖着铺开更像电视弹幕，也避免三条挤在一起 |
| 出现时机 | **打开页面后延迟 3 秒**再开始 | 「打开后过个几秒再出现」：不打断第一眼看完领奖台/榜单 |
| 透明度 | 文字整体 `opacity:.55`（可调） | 「文字透明一点」：看得见但不压内容；白字光晕保证浅底可读 |
| 速度 | 默认 45px/s（可调 20~120） | 「慢的那种」：一条 10~13 秒飘完，接近电视弹幕节奏 |
| 交互 | `pointer-events:none`，无任何点击/悬停处理 | 「不能点击的，点击也不影响动」—— 点击穿透到页面，动画不暂停不重置 |
| 位置 | 默认**领奖台下方**（量底边） | 不遮前三名；弹幕在列表区飘过，与 TV 弹幕一致；预览可切「顶部」对比 |
| 是否联动 `star_override` | **不联动** | 手动单星只影响日报/推送，套到前三会串味（§4.2） |
| 播放节奏 | 默认循环 60s 一轮；可切「每页一次」 | 循环才有弹幕感；60s 稀疏不烦；运营可切一次性 |
| 关闭方式 | 后台总开关 + 系统级 reduced-motion 自动不渲染 | 本期不做页内关闭按钮（见 §13 Q4） |
| 实现技术 | DOM + CSS `transform`（3 个节点） | 比 canvas 简单；3 条弹幕 CSS 足够；reduced-motion 好处理 |

### 3.3 页面效果示意

```
┌────────────────────────────────────────────────────┐
│  masthead（毛玻璃吸顶：标题 / DATA 日期 / 公告行）      │  z 30
├────────────────────────────────────────────────────┤
```

## 4. 数据口径

### 4.1 「前三名」的严格定义

**取当日榜 `items` 中 `rank === 1 / 2 / 3` 的第一个人**（`hasData !== false`），与 `podHtml()` 完全一致：

```js
// 与 podHtml 的 pick(r) 同口径；不按数组前三个硬切，避免并列/缺位时与领奖台不一致
const pick = (r) => listAll.find(x => x.hasData !== false && x.rank === r);
const stars = [pick(1), pick(2), pick(3)].filter(Boolean);
```

- **并列名次**（同分同名次，`daily` 现有口径）：`rank=1` 有两人时，领奖台只展示 `find` 到的第一个；弹幕同样只取第一个 —— **弹幕与领奖台永远同一批人**。
- **缺位**：只有 1~2 名有数据 → 只飘 1~2 条，不补空位、不占空车道。
- **0 条** → 整层不出现（不是空浮层）。
- **谁不进榜**：已删、离团、`hide_in_daily_report=1`、当天无采集记录（`rank=0`）都不进，由 `/daily` SQL 保证。

### 4.2 与「每日之星」单星 / `star_override` 的关系

| 概念 | 现有语义 | 本弹幕是否使用 |
| --- | --- | --- |
| 日报图 / 推送的 🚩 每日之星 | `star_auto()` 当日音浪第一；可被 `star_override`（`称号\|人名\|音浪`）手动改 | **不用** |
| `star_title` 配置（称号） | 单星条/庆祝的标题兜底 | **不直接复用**；弹幕文案固定「今日第X名：名字」 |
| 当日榜前三（领奖台） | 页面已展示的冠军/亚军/季军 | **本弹幕的数据源** |

**为什么不用 `star_auto` 的 top3**：`star_auto` 是单星服务（SQL `LIMIT 1`，且不带 `hide_in_daily_report`/`deleted_at` 过滤）；扩成 top3 会与页面榜单出现口径差。用 `/daily` 的 `items` 是「所见即所得」。

### 4.3 日期跟随

- 弹幕内容**跟随当前选中的业务日**（`curDate`）：切到 `10.12`，数据加载完成后弹幕换成 10.12 的前三名。
- 默认日期 = 昨天（页面既有口径）。
- **月/年口径不显示弹幕**（没有「每日之星」概念）。
- 切换日期但内容没变 → **不重启正在跑的那一轮**（内容签名比较）。

### 4.4 后台显隐开关的叠加

| 后台开关 | 对弹幕的影响 |
| --- | --- |
| `settings.dataEnabled=false` | `/daily` 返回 `dailyEnabled:false`，`listAll` 为空 → 不显示 |
| `settings.daily=false` | 同上 |
| `settings.wave=false` | `wave=null` → 弹幕里**不显示音浪数字**（不是 0） |
| `settings.duration/trend` | 无关（弹幕不显示时长/涨跌） |
| `team_enabled=false` | 整页不可用 → 自然不显示 |

### 4.5 「前三名」是否包含「今日未开播」的人

**不包含。** `rank=0`（当天没采集记录 / 音浪未达开播阈值）的人不进前三。每日之星是「今天的数据荣誉」，没播的人不该被飘出来；与领奖台一致。

## 5. 接口与配置契约

### 5.1 配置结构（后端 `Announcement` 新增字段）

```rust
/// 每日之星前三名漂浮弹幕（2026-10-18，电视弹幕风）
#[derive(Clone, Debug, serde::Serialize, serde::Deserialize)]
#[serde(default)]
pub struct StarDanmaku {
    /// 总开关（默认 false：上线后由运营在后台打开）
    pub enabled: bool,
    /// 展示范围：`top3`（默认）/ `top1`（只飘冠军）
    pub scope: String,
    /// 播放方式：`loop`（默认）/ `once`（本页只跑一轮）
    pub mode: String,
    /// 循环间隔秒（loop 生效；15..3600，默认 60）
    pub interval_sec: i64,
    /// 飘动速度 px/s（慢；20..120，默认 45）
    pub speed: i64,
    /// 每轮条数（三个名次循环铺开；3..12，默认 6）
    pub per_round: i64,
    /// 车道数（领奖台下方到 tabbar 上方等分；3..8，默认 6）
    pub lanes: i64,
    /// 打开页面后延迟几秒再出现（0..10，默认 3）
    pub delay_sec: i64,
    /// 文字不透明度（0.30..0.90，默认 0.55）
    pub opacity: f64,
    /// 是否显示音浪（默认 false：文案只显示「今日第X名：名字」）
    pub show_wave: bool,
}
```

```rust
}
```

> 配置里**没有**「头像」「胶囊样式」「点击行为」：电视弹幕固定纯文字、无交互，不做成可选项。

**序列化口径**：

- 键名 camelCase（`starDanmaku`，字段 `intervalSec/speed/perRound/lanes/delaySec/opacity/showWave`）。
- `GET /api/admin/announcement`（`to_json`）增加 `starDanmaku`，永远带**归一化后的完整对象**。
- `POST /api/admin/announcement` 支持**部分更新**：只传部分字段就只改这些，缺省保持原值（与 `celebrate`/`placements` 同语义）。
- `load_effective()` **不做**内存合成（不参与「items 为空时按 celebrate/champ 合成」的迁移逻辑）。

### 5.2 公开下发

**只加在 `GET /api/public/teams/{team}`（site 接口）**，与 `celebrate`/`items` 同级：

```json

  "published": true,
  "celebrate": { "...": "..." },
  "items": ["..."],
  "starDanmaku": {
    "enabled": true,
    "scope": "top3",
    "mode": "loop",
    "intervalSec": 60,
    "speed": 45,

```

- 无论 `enabled` 真假都下发**完整对象**（前端按 `enabled` 判断；老前端忽略新键不受影响）。
- **不**加到 `GET /api/public/announcements`（弹幕只在登录后的看板出现；将来要登录门也有再补）。
- 前端兜底：`site.starDanmaku` 缺失（老后端）→ 视为 `enabled:false`。

### 5.3 管理端保存与归一化

| 字段 | 归一化规则 |
| --- | --- |
| `enabled` | 只认 bool；缺省保留旧值 |
| `scope` | 只认 `top1` / `top3`，其余回落 `top3` |
| `mode` | 只认 `once` / `loop`，其余回落 `loop` |
| `intervalSec` | clamp `15..=3600`；非数字保持原值 |

| `lanes` | clamp `3..=8`；非数字保持原值 |
| `delaySec` | clamp `0..=10`；非数字保持原值 |
| `opacity` | clamp `0.30..=0.90`；非数字保持原值 |
| `showWave` | 只认 bool；缺省保留旧值（默认 false） |

> 保存时 `version += 1` 沿用现有逻辑；弹幕**不依赖 version**，前端只在内容/开关变化时重启一轮。

### 6.3 JS 控制器（约 130 行，IIFE，避免全局污染）

```js
/* ==================== 🚩 每日之星前三名漂浮弹幕（2026-10-18 电视弹幕风） ====================
   数据：复用 loadData() 的 listAll（/daily items），与 podHtml 同口径取 rank 1/2/3。
   形态：纯文字、半透明、慢速、不可点击（pointer-events:none，无事件监听）。
   位置：量 .st-podium 底边，把 #starDm 放在其下方（不遮前三名）；量不到就兜底。
   生命周期：seq 令牌防过期回调；stop() 清 DOM + 定时器；过屏即删，不累积节点。 */
const starDm = (() => {
  const RM = window.matchMedia ? window.matchMedia('(prefers-reduced-motion: reduce)') : { matches:false };
  let seq = 0, timer = null, lastSig = '', shownOnce = false;

  const cfg = () => (site && site.starDanmaku) || { enabled:false };
  const box = () => $('starDm');
  const eligible = () => {
    const c = cfg();
    return !!c.enabled && view === 'data' && period === 'daily' &&
      !document.hidden && !RM.matches && listAll.length > 0 &&
      !($('gate') && !$('gate').classList.contains('hidden'));
  };
  const pick = (r) => listAll.find(x => x.hasData !== false && x.rank === r);
  function stars() {
    const c = cfg();
    return (c.scope === 'top1' ? [pick(1)] : [pick(1), pick(2), pick(3)]).filter(Boolean);
  }
  function sig(list) { return list.map(x => x.rank + ':' + x.name + ':' + x.wave).join('|'); }

  /** 布局：领奖台下方 → tabbar 上方之间等分 N 条车道（位置多一点）。
      量不到领奖台/底栏时用视口兜底；窄屏车道间距不小于 30px。 */
  function layout() {
    const el = box(); if (!el) return;
    const c = cfg();
    const pod = document.querySelector('.st-podium');
    const tab = document.querySelector('.tabbar');
    const top = pod ? Math.round(pod.getBoundingClientRect().bottom + 10) : 200;
    const bottom = Math.min(tab ? Math.round(tab.getBoundingClientRect().top - 46)
                                : window.innerHeight - 90, window.innerHeight - 70);
    const lanes = Math.min(8, Math.max(3, +c.lanes || 6));
    const gap = Math.max(30, (bottom - top - 10) / Math.max(1, lanes - 1));
    el.style.setProperty('--sd-top', top + 'px');
    el.style.setProperty('--sd-h', Math.max(120, bottom - top) + 'px');
    el.style.setProperty('--sd-gap', gap + 'px');
  }

  function stop() {
    seq++; clearTimeout(timer); timer = null; lastSig = '';
    const el = box(); if (el) { el.innerHTML = ''; el.classList.add('hidden'); }
  }
  const CN = ['', '一', '二', '三'];
  function itemHtml(it, i) {
    const c = cfg();
    const wave = (c.showWave === true && it.wave != null)
      ? '<span class="sd-wv"> · ' + wan(it.wave) + '</span>' : '';
    const text = '今日第' + (CN[it.rank] || it.rank) + '名：' + esc(it.name);
    return '<div class="sd-item sd-rank-' + it.rank + '" style="--sd-lane:' + (i % Math.max(3, +cfg().lanes || 6)) + '">' +
      '<span class="sd-txt"><span class="sd-nm">' + text + '</span>' + wave + '</span></div>';
  }
  function run() {
    const my = ++seq, c = cfg(), base = stars();
    if (!base.length) { stop(); return; }
    const n = Math.min(12, Math.max(3, +c.perRound || 6));
    const list = Array.from({ length: n }, (_, i) => base[i % base.length]);  // 名次循环铺满每轮条数
    if (c.mode === 'once' && shownOnce) { stop(); return; }   // 每页一次：已跑过就不再开
    const el = box(); if (!el) return;
    el.style.setProperty('--sd-op', Math.min(.9, Math.max(.3, +c.opacity || .55)));
    el.innerHTML = '';
    el.classList.remove('hidden');
    layout();
    const speed = Math.min(120, Math.max(20, +c.speed || 45));
    list.forEach((it, i) => {
      setTimeout(() => {
        if (my !== seq) return;
        el.insertAdjacentHTML('beforeend', itemHtml(it, i));
        const node = el.lastElementChild;
        if (!node) return;
        const dur = (window.innerWidth + node.offsetWidth + 80) / speed;
        node.style.setProperty('--sd-dur', dur.toFixed(2) + 's');
        node.addEventListener('animationend', () => node.remove(), { once:true });
        // 无任何 click/pointer 监听：整层 pointer-events:none，点击穿透
      }, i * 1600);   // 条数多：1.6s 错峰，同车道不打架
    });
    const per = Math.max(4000, (window.innerWidth + 260) / speed * 1000);
    const lastIn = (list.length - 1) * 1600;
    const wait = (c.mode === 'once') ? 0 : Math.max(15000, Math.min(3600000, (+c.intervalSec || 60) * 1000));
    if (c.mode === 'once') shownOnce = true;
    timer = setTimeout(() => {
      if (my !== seq) return;
      if (!eligible() || c.mode === 'once') { stop(); return; }
      run();
    }, lastIn + per + wait);
  }
  function refresh() {
    const delay = Math.min(10, Math.max(0, +cfg().delaySec || 0)) * 1000;  // 打开后几秒再出现
    const list = eligible() ? stars() : [];
    const s = sig(list);
    if (!s || s === lastSig) return;   // 无内容 / 内容没变：不打断正在跑的轮次
    lastSig = s;
    stop();
    timer = setTimeout(() => { if (eligible()) run(); }, 900 + delay);  // 等数据渲染 + 用户设定延迟
  }
  return { refresh, stop, layout };
})();
```

接入点：

1. `loadData()` 末尾 `renderList()` 之后 → `starDm.refresh();`
2. `switchView()` 里 → `starDm.refresh();`（离开数据页时内部 `stop()`）
3. `setPeriod()` 末尾 → `starDm.refresh();`
4. `window.addEventListener('resize', () => starDm.layout());`
5. `document.addEventListener('visibilitychange', () => { document.hidden ? starDm.stop() : starDm.refresh(); });`

> 说明：以上是**意图级伪实现**，落地时按 `st_page.html` 现有风格整理；`esc`/`wan`/`TROPHY_SRC` 已存在。`stop()` 时把 `lastSig=''`（保证切走再切回能重开）。

### 6.4 生命周期与时机

| 事件 | 行为 |
| --- | --- |
| 启动 / 登录后 `bootRest` | 等 `loadData()` 成功、`listAll` 有值 → `refresh()` → 约 0.9s + `delaySec`(默认 3s) 后开跑 |
| 切日期 | `loadData()` 覆盖 `listAll` → `refresh()`；签名变了换一轮，没变不打断 |
| 切月/年口径 | `setPeriod` → `refresh()` → `eligible()` 假 → `stop()` |
| 切到 我的/分组/族谱 | `refresh()` → `stop()`；切回数据页且每日口径 → 重新开跑 |
| 静默刷新 | 数据没变不打断；变了无缝换一轮 |
| 页面切后台 | `stop()`；回前台约 1s 后重开 |
| 登录门弹出 | `refresh()` 里 gate 可见 → `stop()`；重新登录后自然恢复 |
| `prefers-reduced-motion` | 不渲染（CSS 隐藏 + JS `eligible()` 双保险） |
| 窗口尺寸变化 | `layout()` 重新量领奖台/tabbar 并重排车道（不重启动画） |
| 页面卸载 | 无需处理（定时器随页面销毁） |

### 6.5 与现有弹层的层级

| 层 | z-index | 弹幕相对关系 |
| --- | --- | --- |
| toolbar（吸顶） | 8 | 弹幕在其下方（位置量领奖台底边） |
| masthead | 30 | 不盖头部 |
| **弹幕层** | **35** | — |
| toast | 40 | 之上 |
| 日历 / 族谱全屏 / 水印 | 50/60/70 | 之上 |
| 公告弹窗 | 89 | 之上（弹窗打开时弹幕被盖住，且不接收事件） |
| 登录门 | 90 | 之上 |
| 消息弹窗 / 引导 | 95/100 | 之上 |
| 彩带 canvas | 9999 | 之上（庆祝彩带最顶） |

> 弹幕是「气氛」，任何需要用户处理的弹层都应压过它。

### 6.6 性能与内存

- 同时在屏约 3~6 个 DOM 节点（每轮最多 12 条，过屏即删），`transform` 动画（合成层，不触发布局）。
- `animationend` 即 `remove()`，不累积节点。
- 定时器只有 1 个（下一轮）+ 每轮 N 个错峰 `setTimeout`（N ≤ 12）；`seq` 令牌保证过期回调直接返回。
- `document.hidden` 时清空；后台标签页不耗 CPU。
- 不轮询、不发请求：数据已由 `loadData()` 拉过。
- 无事件监听在弹幕节点上（零交互），点击穿透不阻断任何页面操作。

### 7.2 多车道与节奏

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 车道数 | **6**（3~8 可调；按 `i % lanes` 循环） | 领奖台下方 → tabbar 上方等分，位置多、不挤 |
| 车道间距 | 由布局动态算（最低 30px） | 6 车道约 60~75px，竖着铺开像电视弹幕 |
| 入场错峰 | 1.6s / 条 | 每轮 6 条时同车道不打架；条数越多铺得越开 |
| 出现延迟 | **打开页面后 3 秒**（0~10 可调） | 「过个几秒再出现」，先让人看完领奖台 |
| 起点 | 屏外右侧（`left:100%`） | 不会突然出现在屏幕中间 |
| 终点 | 完全飘出左侧（`translate3d(calc(-100% - 100vw))`） | 过屏即移除 |
| 速度 | 默认 **45px/s**（可配 20~120） | 390px 屏一条 10~13 秒 |
| 循环间隔 | 默认 60s（可配 15~3600） | 从「最后一条入场」起算 |
| 上下浮动 | ±2px，3.6s 循环 | 「漂浮」质感，幅度小不晕 |

### 7.3 交互口径（用户明确要求）

| 行为 | 结果 |
| --- | --- |
| 点击弹幕文字 | **无反应**；事件穿透到下面的榜单行（该复制照常复制） |
| 鼠标悬停 | 无 hover 样式、无 cursor 变化 |
| 点击 / 滚动页面 | **动画继续**，不暂停、不重置、不加速 |
| 触摸滑动 | 正常滚动页面，弹幕不拦截 |
| 键盘 | 弹幕不可聚焦、不在 tab 序 |

> 实现上：`#starDm` 与 `.sd-item` 均为 `pointer-events:none`，且**不挂任何 click/pointer 监听**。

### 7.4 响应式

| 断点 | 调整 |
| --- | --- |
| ≥ 430px（大屏手机/桌面/TV） | 默认规格；内容 `.wrap` 居中，弹幕横穿整屏 |
| 360~429px | 默认 |
| ≤ 359px | 字号 -0.5px；名字 `max-width:6.5em`；车道高 40px |
| 横屏 / `height < 500px` | 车道收成 2 条（冠军+亚军）或层高 118px |

### 7.5 可访问性

- `aria-hidden="true"`：纯装饰，不进无障碍树。
- 不可聚焦、无按钮、`pointer-events:none`。
- `prefers-reduced-motion: reduce`：**完全不渲染**（不是留静态文字）。
- 半透明文字对比度：55% 不透明度 + 白字光晕，在浅底（`#fcf8fb`）上仍可读；若调高透明度到 0.9，仍是弱化装饰，不与正文抢层级。

## 9. 边界与降级

| 场景 | 预期行为 |
| --- | --- |
| 后台总开关关 | 不渲染；`refresh()` 立即 `stop()` |
| 老后端（无 `starDanmaku`） | 前端视为 `enabled:false`，不渲染不报错 |
| 当天 0 人有数据 / 接口失败 | 不渲染；不出现空浮层 |
| 只有 1~2 人有数据 | 只飘 1~2 条，其余车道空着 |
| 并列名次 | 与领奖台同口径取 `find` 到的第一个 |
| 后台关音浪（`wave=null`） | 不显示数字（不是 0）；`showWave=false` 同理 |
| 艺名超长 | 8em 省略号 |
| 点击弹幕 / 点击页面 / 滚动 | 无反应 / 穿透 / 动画继续（§7.3） |
| 在「我的/分组/族谱」页 | 不显示 |
| 月/年口径 | 不显示 |
| 登录门打开 / token 失效 | 不显示（层在门之下且 `eligible()` 判断） |
| 公告弹窗打开 | 弹幕被 89 层盖住；翻页不受影响 |
| 页面切后台 | 停止清理；回前台重开（重新计延迟） |
| 打开页面 | 停 3 秒再开始飘（不打断第一眼） |
| `prefers-reduced-motion` | 不渲染 |
| 快速连点日期 | 只认最后一次 `listAll`；签名相同不重开 |
| 内容签名相同但切走再切回 | 切回时重新开轮（`stop` 时清 `lastSig`） |
| 同一页多次 `refresh()` | `seq` 令牌 + `clearTimeout`，只有一组定时器 |
| 窗口 resize / 旋屏 | `place()` 重新量位置，不重启动画 |
| 网络断开后恢复 | 静默刷新拿到新数据自然换一轮；拿不到就维持/停止（不报错） |

## 12. 风险与回滚

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 半透明文字看不清 | 白飘 | 默认 55% + 白字光晕；后台可调到 90%；奖杯/名字加浓 |

| 低端机掉帧 | 滚动卡顿 | 3 个节点 + transform；后台暂停；仍卡就默认关 |
| 与公告弹窗/登录门叠层冲突 | 盖住弹窗/挡按钮 | z-index 35；`pointer-events:none` |
