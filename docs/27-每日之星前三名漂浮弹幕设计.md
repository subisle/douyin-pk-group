## 1. 需求理解与范围

### 1.1 用户原话（按时间）

> 「准备做一下这个漂浮的弹幕效果。为每日之星前三名的」
> 「弹幕使用电视那种弹幕透明度低，慢的那种文字透明一点，不能点击的。点击也不影响动。」
> 「可以多一点，每日之星不要，文字为 今日第一名：第二名，第三名。这样数量可以多一点。」
> 「**打开立即开始即可，这个弹幕不能遮挡原来的显示的内容。支持评论，右下角添加一个评论功能，用户评论可以设置显示时间最高为两天**」

### 1.2 落成的规格

1. **常驻弹幕带（不遮挡）**：弹幕带是页面的一段**真实占位区域**，不是 `position:fixed` 浮层。领奖台、榜单从它下方开始；滚动时弹幕带随页面走，不覆盖任何数据卡片。
2. **打开立即开始**：删除 v1.3 的 3 秒延迟；数据一到就开飘（首条 ≈ 0.3s 后入场）。
3. **弹幕内容**：
   - 名次条（固定格式）：`今日第一名：张三` / `今日第二名：李四` / `今日第三名：王五`，按轮次循环铺满配置条数；
   - 用户评论：`「内容」 · 艺名`，青色文字（与名次条的金/银/铜区分）。
4. **评论功能**：
   - 右下角 💬 FAB → 底部弹层（输入 + 展示时长 + 发送）；
   - 展示时长：1 小时 / 6 小时 / 12 小时 / 1 天 / 2 天（**最长 2 天**，服务端强制）；
   - 评论到期自动从弹幕带消失（服务端不再下发 + 前端本地过滤）；
   - 管理员可隐藏/删除违规评论。

### 1.3 做 / 不做

| 做 | 不做 |
| --- | --- |
| 常驻弹幕带（文档流，不遮挡） | 覆盖在榜单/领奖台上的浮层弹幕 |
| 名次条 + 用户评论混合轮播 | 视频/直播弹幕、点赞、表情包 |
| 评论输入（≤30 字）+ 展示时长（≤48h） | 评论回复/盖楼/@ |
| 登录态校验 + 限频 + 管理端审核/隐藏 | 匿名游客评论（默认不允许，见 §13） |
| 评论到期自动消失（服务端时间） | 永久保留的评论区历史列表（本期不做；可后续加） |
| 后台开关：车数/速度/透明度/条数/评论开关/最长时长 | 用户自定义颜色/字体/皮肤 |

### 1.4 非目标

- 不改 `/daily` 接口既有字段与语义；名次条仍从 `/daily` 派生。
- 不改推送/日报图的「🚩 每日之星」单星口径。
- 不引入外网资源（无新图标字体；💬 用内联 SVG/emoji）。

## 3. 总体方案

### 3.1 布局（常驻弹幕带，不遮挡）

```
┌──────────────────────────────────────────────┐
│ masthead（吸顶：标题 / DATA 日期 / 公告行）      │
├──────────────────────────────────────────────┤
│ toolbar（每日/每月/每年 + 日期条）              │
├──────────────────────────────────────────────┤
│ ▍今日弹幕（常驻带，默认 5 车道 ≈ 160px）         │
│   今日第一名：张三 ──────────────▶             │
│   「张三加油！」 · 小王 ──────────▶             │
│   今日第二名：李四 ─────────────▶              │
│   ……（车道循环）                               │
├──────────────────────────────────────────────┤
│ 领奖台（李四 / 张三 / 王五）                    │ ← 从带下方开始
│ 榜单列表（可滚动）                              │
│                                        💬      │ ← FAB（右下角）
├──────────────────────────────────────────────┤
│ tabbar（看板 / 分组 / 族谱 / 我的）              │
└──────────────────────────────────────────────┘
```

- 弹幕带是**普通文档流** `section`（不是 fixed/absolute 浮层），高度由车道数决定；`overflow:hidden` 只在带内部裁切。
- 数据内容（领奖台/榜单）排在带之后，**任何文字都不会压到榜单上**。
- 滚动时弹幕带随内容向上滚走（不吸顶）—— 用户往下看榜单时，带自然离开视口，不打扰阅读。若后续希望「吸顶常驻」，只改一个 `position:sticky; top:...`，但本期不做。
- 💬 FAB 是**按钮**不是弹幕，固定在右下角（tabbar 上方），点击打开评论弹层；不挡弹幕带。

### 3.2 数据流

```
GET /api/public/teams/{team}/daily          GET /api/public/teams/{team}/danmaku
        │  items（rank/name/wave）                 │  comments[{id,content,author,until}]
        ▼                                          ▼
   名次条队列（rank1/2/3 循环）  ───────►  合并调度器（名次条 + 评论，循环上车）
                                                   │
                                    弹幕带内按车道、1.5s 一条、右→左慢速漂
                                                   │
                         每轮结束等 intervalSec 再来；评论到期本地过滤 + 5 分钟重拉

POST /api/public/teams/{team}/danmaku（X-My-Token）
        │  {content, hours}
        ▼
   校验 → 落库(display_until = now + hours) → 返回 {id, until}
        → 前端立即插入队列 + 飘一条 + toast
```

### 3.3 关键设计决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 弹幕位置 | **常驻带（文档流）** | 用户明确「不能遮挡原来的显示的内容」；浮层方案必然压内容 |
| 开始时机 | 数据到位立即开始，无延迟 | 用户明确「打开立即开始」 |
| 名次条数据 | `/daily` 的 `items`（与领奖台同口径） | 零新增接口；与榜单一致 |
| 评论存储 | 新表 `st_danmaku_comments` | 需要时效（display_until）、审核状态、作者/团别 |
| 评论时效 | 用户选 1h/6h/12h/1d/2d，服务端 clamp ≤48h | 用户口径「最高两天」；服务端时间为准，防本地改时间 |
| 评论资格 | 登录账号（X-My-Token） | 展示端本来就有登录体系；防匿名刷屏；管理端审核兜底 |
| 评论显示 | `「内容」 · 艺名`，青色 | 与名次条区分；是否显示艺名见 §13 |
| 评论审核 | 先发后审：管理员隐藏/删除 | 直播场景要即时出现；违规事后处理 |
| 限频 | 30 秒/条、10 条/小时、5 条未过期/人 | 防刷屏，同时不打扰正常互动 |
| 弹幕共享 | 名次条 + 评论混排；评论到期消失 | 弹幕带就一条流，阅读节奏统一 |
| 实现技术 | DOM + CSS transform（评论/名次条同一种 item） | 与 v1 一致；无 canvas |

## 4. 数据口径

### 4.1 名次条（前三名）

与领奖台完全同口径：

```js
const pick = (r) => listAll.find(x => x.hasData !== false && x.rank === r);
const stars = [pick(1), pick(2), pick(3)].filter(Boolean);
```

- 并列名次：取 `find` 到的第一个（与领奖台一致）。
- 缺位：只飘 1~2 条。
- 0 条：名次条不出现（评论仍可飘）。
- 日期跟随 `curDate`；月/年口径不显示弹幕带。
- 后台音浪关：名次条不带音浪（默认也不带）。

### 4.2 评论可见性

| 条件 | 规则 |
| --- | --- |
| 未过期 | `display_until > now()`（服务端 `now()`，不信客户端） |
| 未隐藏 | `hidden = 0` |
| 团别 | 路径团 `male/female`：返回 `team = 路径团 OR team = 'all'`；路径 `all`：不过滤（管理员/游客聚合页） |
| 排序/数量 | 按 `created_at DESC` 取最近 100 条（弹幕池足够；不一次拉全量） |
| 过期 | 服务端不再返回；前端每轮本地再过滤一次（防止长驻页面显示过期评论） |
| 刷新 | 页面加载 + 每 5 分钟 + 切回前台/切回数据页时静默重拉 |

### 4.3 评论内容与时长

| 项 | 规则 |
| --- | --- |
| 长度 | trim 后 **1~30 个字符**（按 Unicode 字符数；换行/控制字符拒绝或压成空格） |
| 时长 | 整数小时 `1 / 6 / 12 / 24 / 48`（前端下拉）；服务端 clamp `1..=comment_max_hours`（默认 48） |
| 纯文本 | 全链路转义（`textContent` / `esc()`），绝不进 innerHTML |
| 禁 URL？ | 不做自动识别/跳转；纯文本展示即可（避免钓鱼跳转） |
| 重复 | 同一账号 10 分钟内相同内容 → 400「不要重复发送」 |

### 4.4 权限

- **发布**：必须有效 `X-My-Token`；账号团别需与路径团兼容（`my_team_allows`，管理员跨团放行）。
- **查看**：与 `/daily` 同一登录门（`gate_team` / `login_required`）。
- **审核**：管理端 `ADMIN_PASSWORD` 会话（现有 admin 鉴权），可隐藏/恢复/删除。

## 5. 数据模型与接口契约

> ⚠️ **本期（v2.1）只实现弹幕带；§5.1~5.4 的评论表/接口、§6.3 评论交互、§8.2 评论审核按用户口径「评论先不做、后续单独开」保留为后续设计，代码未落。§5.5~5.6 的弹幕配置已实现。**

### 5.1 评论表（迁移 `042_st_danmaku_comments.sql`）

```sql
CREATE TABLE IF NOT EXISTS st_danmaku_comments (
  id             BIGSERIAL PRIMARY KEY,
  team           VARCHAR(16)  NOT NULL DEFAULT '',   -- male / female / all
  author_account VARCHAR(64)  NOT NULL DEFAULT '',   -- my_accounts.name（展示用艺名）
  author_person_id BIGINT     NOT NULL DEFAULT 0,    -- 绑定主播 id（0 = 未绑定/管理员观看账号）
  content        VARCHAR(60)  NOT NULL,              -- 上限 30 字符（VARCHAR 留余量）
  created_at     TIMESTAMPTZ  NOT NULL DEFAULT now(),
  display_until  TIMESTAMPTZ  NOT NULL,              -- now() + hours（≤ 48h）
  hidden         SMALLINT     NOT NULL DEFAULT 0,    -- 0 正常 / 1 管理员隐藏
  ip_hash        VARCHAR(64)  NOT NULL DEFAULT ''    -- 审计用（SHA-256 截断，不落明文 IP）
);
CREATE INDEX IF NOT EXISTS idx_st_dm_active
  ON st_danmaku_comments (team, display_until) WHERE hidden = 0;
CREATE INDEX IF NOT EXISTS idx_st_dm_author
  ON st_danmaku_comments (author_account, created_at DESC);
```

- 幂等：`IF NOT EXISTS`，可重放。
- 不建外键（与现有表风格一致，避免删账号卡住历史评论）。
- 不存明文 IP；`ip_hash` 仅审计/排障。

### 5.2 `GET /api/public/teams/{team}/danmaku`

- 鉴权：与 `/daily` 同（`gate_team`）。
- 响应：

```json
{
  "published": true,
  "serverTime": "2026-10-18T01:30:00+08:00",
  "comments": [
    { "id": 12, "content": "张三今天太猛了！", "author": "小王", "until": "2026-10-20T01:20:00+08:00" }
  ]
}
```

- 只返回 `hidden=0 AND display_until > now()`，按 `created_at DESC LIMIT 100`。
- `author` 为空（历史/异常）→ 前端只显示内容。

### 5.3 `POST /api/public/teams/{team}/danmaku`

- 头：`X-My-Token`（必填，否则 401）。
- 体：`{ "content": "张三加油！", "hours": 24 }`
- 成功：`200 { "ok": true, "id": 13, "until": "...", "hours": 24 }`
- 校验与错误：

| 情况 | 状态码 | 文案 |
| --- | --- | --- |
| 未登录/过期 | 401 | 请先登录后再评论 |
| 内容为空 / 超 30 字 | 400 | 评论内容需为 1~30 个字 |
| hours 非法 | 400 | 展示时长需在 1~48 小时之间 |
| 团别不符 | 401 | 该账号不属于本团 |
| 限频（30s / 10条每小时 / 5条未过期） | 429 | 评论太频繁，稍后再试 / 你未过期的评论已达 5 条 |
| 10 分钟内重复内容 | 400 | 不要重复发送相同内容 |
| 写库失败 | 500 | 评论发送失败，请稍后重试 |

- 限频实现：`WHERE author_account = ? AND created_at > now() - interval '30 seconds'` 判 30s；`count(*) ... 1 hour` 判 10；`count(*) ... display_until > now()` 判 5。
- 团别：`team` 取路径团（`male/female`；`all` 页面用账号绑定团，管理员用 `all`）。

### 6.2 弹幕调度（名次条 + 评论）

```js
const starDm = (() => {
  let seq = 0, timer = null, lane = 0, lastRankSig = '', comments = [];
  const cfg = () => (site && site.starDanmaku) || { enabled:false };
  const eligible = () => cfg().enabled && view === 'data' && period === 'daily'
    && !document.hidden && !matchMedia('(prefers-reduced-motion: reduce)').matches
    && !($('gate') && !$('gate').classList.contains('hidden'));

  /** 一轮的条目：名次条（循环 perRound 条）+ 未过期评论 */
  function buildCycle() {
    const c = cfg();
    const base = stars();                       // 见 §4.1
    const out = [];
    if (base.length) {
      const n = Math.min(9, Math.max(3, +c.perRound || 3));
      for (let i = 0; i < n; i++) out.push({ kind:'rank', ...base[i % base.length] });
    }
    const now = Date.now();
    for (const cm of comments) {
      if (!cm.until || new Date(cm.until).getTime() > now) out.push({ kind:'comment', ...cm });
    }
    return out;
  }

  function run() {
    const my = ++seq, c = cfg();
    if (!eligible()) { hide(); return; }
    const el = $('starDm'); if (!el) return;
    show();
    el.style.setProperty('--sd-op', Math.min(.9, Math.max(.3, +c.opacity || .6)));
    el.innerHTML = '';
    lane = 0;
    const list = buildCycle();            // 评论 + 名次条
    const speed = Math.min(120, Math.max(20, +c.speed || 45));
    list.forEach((it, i) => setTimeout(() => {
      if (my !== seq) return;
      spawn(el, it, speed);
    }, i * 1500));
    const pass = (window.innerWidth + 260) / speed * 1000;
    const lastIn = Math.max(0, list.length - 1) * 1500;
    const wait = Math.max(15000, Math.min(3600000, (+c.intervalSec || 60) * 1000));
    timer = setTimeout(() => { if (my === seq) run(); }, lastIn + pass + wait);
  }

  function spawn(el, it, speed) {
    const c = cfg();
    const lanes = Math.min(6, Math.max(3, +c.lanes || 5));
    const node = document.createElement('div');
    node.className = 'sd-item ' + (it.kind === 'rank' ? 'sd-rank-' + it.rank : 'sd-cmt');
    node.style.setProperty('--sd-lane', lane++ % lanes);
    // 文案用 textContent 拼，绝不 innerHTML 注入
    const txt = document.createElement('span');
    txt.className = 'sd-txt';
    if (it.kind === 'rank') {
      const cn = ['', '一', '二', '三'][it.rank] || it.rank;
      txt.textContent = '今日第' + cn + '名：' + (it.name || '');
      if (c.showWave === true && it.wave != null) {
        const wv = document.createElement('span'); wv.className = 'sd-wv';
        wv.textContent = ' · ' + wan(it.wave); txt.appendChild(wv);
      }
    } else {
      txt.textContent = '「' + (it.content || '') + '」';
      if (it.author) {
        const au = document.createElement('span'); au.className = 'sd-au';
        au.textContent = ' · ' + it.author; txt.appendChild(au);
      }
    }
    node.appendChild(txt);
    el.appendChild(node);
    const dur = (window.innerWidth + node.offsetWidth + 80) / speed;
    node.style.setProperty('--sd-dur', dur.toFixed(2) + 's');
    node.addEventListener('animationend', () => node.remove(), { once:true });
    // 不挂任何 click/pointer 监听：整带 pointer-events:none，点击穿透
  }
  ...
})();
```

- **立即开始**：`loadData()` 成功 → `refresh()` → 不等待/不延迟，直接 `run()`（首条入场 ≈ 数据渲染后 0~300ms）。
- 名次条内容签名（rank:name:wave）没变时不打断当前轮；评论变化（新增/过期）由 `refreshComments()` 重拉后按需重建队列。

### 6.3 评论加载 / 发布 / 过期

| 时机 | 行为 |
| --- | --- |
| 进入数据视图（每日口径） | `GET .../danmaku` 拉活跃评论；合并进下一轮 |
| 每 5 分钟 | 静默重拉（只更新评论池，不打断当前轮） |
| 切回前台 / 切回数据页 | 重拉一次 |
| 本地到期判断 | `spawn`/`buildCycle` 里按 `until > now` 过滤；到期的 DOM 自然离场（已过屏的早删了） |
| 发布成功 | 把返回的评论塞进本地池（`until` 用服务端值）→ 立即飘一条 → toast「评论已发送，展示 X」 |
| 发布失败 | 401 → 关弹层并弹登录门；429 → toast 限频文案；400 → 红字提示（内容/时长） |
| 未登录点 💬 | 直接打开登录门（或提示「登录后可评论」并弹登录） |
| 后台 `commentsEnabled=false` | 不拉评论、隐藏 💬；已有评论也不飘 |

### 6.4 生命周期 / 视图联动

| 事件 | 行为 |
| --- | --- |
| 数据视图 + 每日口径 | 显示弹幕带与 💬；立即开跑 |
| 切月/年口径 | 弹幕带与 💬 隐藏；停定时器、清 DOM |
| 切 分组/族谱/我的 | 同上（`refresh()` 里判断） |
| 切回数据页 | 重新拉评论 + 重新开跑（立即） |
| 页面切后台 | 停定时器、清 DOM；回前台立即重启 |
| 登录门打开 | 停止并隐藏；登录成功后恢复 |
| 窗口 resize / 旋屏 | 重新计算带内车道间距（`--sd-gap`），不重启动画 |
| 滚动 | 弹幕带随文档流滚走（不吸顶），不遮挡内容 |

### 6.5 安全与转义（评论是用户输入）

- **全链路 textContent**：评论内容、艺名都不进 `innerHTML`；页面里现有 `esc()` 也仅用于拼字符串场景，本组件优先 DOM API。
- 长度服务端 + 前端双限（30 字）；控制字符/换行服务端拒绝或压成空格。
- 不自动识别 URL、不做跳转，纯文本展示。
- 发布必须登录；限频三层（30s / 10 条每小时 / 5 条未过期）；管理员可隐藏/删除。
- `ip_hash` 只存哈希，不落明文；日志不打印评论全文（可打 id/长度）。
- 评论接口与 `/daily` 同登录门，未登录不可拉取。

### 6.6 性能与内存

- 弹幕带同时最多 ≈ 车道数 × 2 个 DOM 节点（过屏即删）。
- 定时器：1 个下一轮 + N 个错峰；`seq` 令牌防过期回调。
- `document.hidden` 全停；评论 5 分钟才拉一次。
- 弹幕带高度有限（5 车道 ≈ 160px），页面内容不被压得太狠。
- FAB/弹层按需显示，不干扰页面渲染。

## 9. 边界与降级

| 场景 | 预期行为 |
| --- | --- |
| 后台总开关关 | 弹幕带与 💬 都不显示 |

| 重复内容（10 分钟内） | 400 文案提示 |

| 切换视图/口径 | 带隐藏、停表、清 DOM；切回重新拉评论并立即开跑 |
| 公告弹窗 / 登录门打开 | 带在文档流里（不在弹层之上）；弹窗盖住页面时自然被盖住 |
| 页面切后台 | 停表清 DOM；回前台立即重启 |
| `prefers-reduced-motion` | 不飘（静态提示），评论仍可发；带保留 |
| 窗口 resize / 旋屏 | 重算车道间距，不重启动画 |
| 快速切日期 | 只认最后一次 `listAll`；评论池不重复拉 |

## 12. 风险与回滚

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 评论被刷屏/广告 | 展示端难看 | 登录 + 30s/10条/5条未过期限频 + 管理员隐藏 + 10 分钟重复内容拦截 |
| 评论含 XSS | 页面被注入 | 全链路 textContent/esc；服务端限制长度与控制字符；不渲染 HTML |
| 常驻带占地方 | 首屏可见榜单变少 | 默认 5 车道可配 3~6；带高按车道算；用户滚动后带离开视口 |
| 评论过期不消失 | 旧评论一直飘 | 服务端按 `display_until` 过滤 + 前端每轮本地过滤 + 5 分钟重拉 |
| 未登录用户点评论 | 无反应/困惑 | 直接弹登录门 + 文案「登录后可评论」 |
| 团别串评论 | 男团页面看到女团评论 | `team` 落库 + GET 按团过滤（all 聚合页例外） |
| 老配置/老前端 | 反序列化失败/不显示 | `serde(default)` + 前端缺字段兜底；新表迁移幂等 |
| 时间被本地篡改 | 评论超期仍显示 | 服务端 `display_until` 为准；前端只做辅助过滤 |

**回滚**：后台关弹幕带总开关（无需发版）→ 前端不再显示；评论功能单独开关（`commentsEnabled=false`）可只关评论；极端情况回滚 T4 页面代码，表与接口留着不碍事。
