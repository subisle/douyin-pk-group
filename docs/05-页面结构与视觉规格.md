## 1. 角色与核心使用场景

| 角色 | 入口 | 核心场景 |
| --- | --- | --- |
| **运营/管理员**（需要口令） | `/admin/data`、`/admin/import`、`/admin/streamers`、`/admin/claims`、`/admin/visits`、`/admin/lineage`、`/admin/group`、`/admin/bots`（`apps/douyin-web`，history 路由；旧 hash 路由 `/#/home`、`/#/data`、`/#/board` 随 `apps/web` 一并删除） | ① 开赛前确认数据新鲜度 → ② 粘贴名单解析 → ③ 一键均衡分组 → ④ 拖拽微调、锁人、修约束 → ⑤ 导出长图/保存方案 → ⑥ 上架分享链接给主播群 |
| **主播/观众** | `/st/m`、`/st/f`（全站登录门，开 `loginRequired` 时可关） | 比赛日打开分享链接看「自己第几组、几点开赛、对手是谁」；平时看每日音浪榜和总音浪榜 |

一句话概括：**管理端是把「名单 + 音浪数据」变成一份可微调、可复用分组方案的工作台；展示端是把方案变成一张手机友好的、随时自动更新的公告页。**

## 2. 页面列表（站点地图）

> ⚠️ 下面这份是**已冻结**的 `apps/web`（hash 路由 `/#/…`，只做兼容、不再扩展）。
> 现役管理端是 `apps/douyin-web`，**history 路由统一挂在 `/admin` 下**
> （`/admin/data`、`/admin/import`、`/admin/streamers`、`/admin/claims`、
> `/admin/lineage`、`/admin/group`、`/admin/bots`），页面清单与模块结构见
> `docs/06` §3 / §4；根路径 `/` 是对外展示页。

```
管理端（需口令，/api/* 带 Bearer token）
├── /#/home     首页          HomeView
├── /#/data     主播数据       StreamerView
└── /#/board    PK 分组看板    BoardView（+ 8 个子组件）

展示端（免登录，/api/public/*）
├── /s/:planId  方案展示页     ShareView(planId)
└── /st         公告页         ShareView()

通用
└── AuthGate    登录门（未登录/401 时覆盖三页）
```

路由是 hash 路由（`lib/nav.ts`）：刷新、前进后退、分享链接都落在同一页；
展示端页内三个分页（每日音浪 / PK 分组 / 总音浪）是组件状态切换，URL 不变。

## 3. 每个页面的模块结构

### 3.1 AuthGate（登录门）

| 模块 | 说明 |
| --- | --- |
| 标题/说明区 | 说明这是内部工具、需要口令 |
| 口令输入 + 提交 | `POST /api/auth/login` 换内存 token；失败给一行红字原因 |
| 状态 | 未登录遮罩三页；已登录后 token 存内存，8h 空闲失效 → 任意接口 401 时弹回此门 |

### 3.2 首页 `/#/home`（HomeView）

| 模块 | 内容 | 交互/状态 |
| --- | --- | --- |
| 数据新鲜度卡 | 最新采集日期 + 「今天/昨天/N 天前」口径；日期白名单横滑条 | 点击日期切换基准日；`gap=null` 时如实显示「还没有采集到任何日期」，不假装新鲜 |
| 方案概况卡 | 当前方案的策略标签（蛇形/蛇形+同门回避/顺序/随机）、音浪口径（总音浪 / 近 N 天）、组数与人数 | 策略与口径可在这里直接调整 |
| 健康状态 | `db.ok` 数据库连通性提示 | 数据库挂了给 warn 提示「展示页将降级用快照」 |
| 入口区 | 两张入口卡 → 主播数据 / PK 分组 | 点击 hash 跳转 |

### 3.3 主播数据 `/#/data`（StreamerView）

| 模块 | 内容 | 交互/状态 |
| --- | --- | --- |
| 工具条 | 检索框（320ms 防抖）、排序切换（音浪高→低 / 低→高 / 名字）、口径切换（总/近 N 天） | 分享 `/st` 公告开关也在这里（「展示页显示」开关） |
| 音浪排行表 | 全场名次 + 每行开播/未开播状态；粘性表头 | 行 hover 整行点亮；CSV 导出按钮 |
| 主播库检索 | 模糊搜主播 + 简要卡（AnchorBrief） | 空结果给「没有匹配的主播，换个词试试」 |
| 趋势图 | TrendChart：单个主播近 N 天音浪曲线 | 选中主播联动；数据不足时降级为提示而非空图 |
| 强制刷新 | 绕过 10 分钟 WaveCache 重新拉数 | 请求中按钮转圈，完成后行内提示 |

### 3.4 PK 分组 `/#/board`（BoardView，核心工作台）

自上而下：

| 子模块 | 职责 |
| --- | --- |
| **RosterImport** 名单解析 | 大文本框粘贴名单 → 「解析」调 `/api/group/arrange` 前置匹配；**匹配不上的名字标红**，下拉手动绑定主播库账号，未绑定按 0 音浪参赛；师傅/队长标注（`A➕B`、`A（B）`两种写法） |
| **WaveConfig** 口径配置 | total / lastN、近 N 天数、每组人数、组数 |
| **BoardTools** 工具条 | 自动重排、均衡微调、自动修正、组内按音浪排序、全局找人（命中卡片高亮并滚动到位）、紧凑模式开关、撤销/重做（≤50 步）、快捷键 `Cmd/Ctrl+Z` / `Cmd/Ctrl+Shift+Z` |
| **GroupBoard** 看板主体 | 组卡片列阵 + 底部「未分组」区。卡片（PlayerCard）显示名字、音浪、约束/锁定/超员标记；组头显示 `n/上限`、开赛时段、`+` 增补入口 |
| **ExportBar / StatsBar** | 均衡度（极差）摘要、约束冲突清单（明确列出哪条没满足，不静默失败）、导出长图（750px 宽 export-stage 离屏渲染） |
| **HistoryPlans** 历史方案 | 保存/载入/删除方案；每条显示**上架状态**，可复制 `/s/:planId` 链接、一键上架/下架 |

### 3.5 展示端 `/s/:planId`、`/st`（ShareView，苹果风）

| 模块 | 内容 | 交互/状态 |
| --- | --- | --- |
| 深色头部（masthead） | 标题 + 开赛时段说明；对角光 + 颗粒氛围层 | 静态 |
| 赛程条 | 9 组时段胶囊横滑（组数不足时**补内置空组占位**，时段卡位先摆出来），右侧 44px 渐隐提示「还有组」 | 横向滚动（细滚动条 rail） |
| 页内分页 | **每日音浪**（选日期 + 每行开播状态）/ **PK 分组**（组内按音浪名次，组间占比条）/ **总音浪**（全场累计，同分并列） | 纯状态切换；PK 分组 tab 只在比赛日（最新采集日==今天）展示 |
| 音浪隐藏开关 | 管理端关闭后后端**不下发任何数字**，两个榜单模块整体消失，只剩分组名单 | — |
| 数据口径 | 音浪实时取（WaveCache），每分钟静默刷新；数据库挂了降级用方案快照并标 `stale` 徽标 | — |

## 4. 视觉风格关键词

来自 `index.css` 的 design tokens，一句话：**「冷灰纸面上的靛蓝工具」——克制的运营后台 + 苹果风的对外公告。**

| 关键词 | 落地方式 |
| --- | --- |
| **浅冷灰画布** | `#f7f8fa` canvas + 顶部极轻冷色渐晕（canvas-glow），大面积区域不是死白 |
| **靛蓝品牌色** | `#4f46e5`（hover 加深 `#4338ca`），用于导航指示条、激活态、焦点环、选中文本底色；**不用紫蓝/青色 radial 渐变**（明令禁止的 AI 味） |
| **三层灰阶文字** | ink `#101828` / ink2 `#475467` / ink3 `#98a2b3` |
| **发丝线 + 小标签表头** | 表格用 `color-mix` 淡分隔线、11px 大写字距表头，行 hover 整行点亮 |
| **三档阴影，不随手加第四档** | raise（卡片）→ float（浮层/弹窗）→ bar（吸顶条），卡片另有 1px 顶部高光内边 |
| **语义色只四个** | good 绿 / warn 橙 / bad 红 / info 蓝，均配 soft 底色做胶囊与提示条 |
| **数字排版强迫症** | 所有数值 `tabular-nums` + 大数字负字距 `.figure`——拖拽重算时音浪数值不左右跳 |
| **半径三档** | 控件 8 / 卡片 10 / 面板 12，不再有别的圆角 |
| **毛玻璃吸顶** | 顶栏 `backdrop-filter: blur(12px) saturate(1.6)` + 半透明底 |
| **展示端氛围** | 深色头部 = 一层中性偏冷顶光（透明度 ≤6%）+ SVG 噪点颗粒；名单行发丝分隔，扫名字比彩色胶囊快 |
| **字体** | 系统栈（PingFang SC / Noto Sans SC 优先），零外部字体请求 |

## 5. 交互清单（重点：看板）

- **拖拽**：`apps/douyin-web/src/pk/GroupPage.tsx` 用**指针事件（pointer events）**自己实现
  （鼠标 / 触屏 / 触控笔同一套），不依赖 dnd-kit，也不用 HTML5 `draggable`（后者在触屏上
  完全不触发且没有跟手的幽灵卡片）；跨组 / 组内拖拽，拖起卡片换 `shadow-drag` 抬升。
- **卡片菜单**（移动端等价操作）：移动到第 N 组 / 交换（选目标组）/ 移出到未分组；未分组的人点击名字归回任意组。
- **锁定**：锁某人后自动重排与均衡微调都不动他，卡片有锁标。
- **均衡微调**：只接受让极差变小的交换；做不了时提示「当前没有能降低极差的交换」。
- **自动修正**：一键按当前策略重排并修复约束。
- **约束冲突可视化**：前端从 `/api/group/constraints` 拉约束副本做高亮，冲突在看板上明确列出。
- **增补/删组**：组头 `+` 只插一人不重排；删非空组时成员自动进「未分组」，不弹拒绝对话框。
- **超员**：组头显示 `9/8` 并变色，超员组数在看板顶部单独汇总提示。
- **快捷键**：撤销/重做；输入框聚焦时不劫持。
- **全局找人**：搜索命中高亮 + `scrollIntoView`，组内和未分组一起命中。
- **导出**：html-to-image 离屏 750px 白底长图，临时挂 body 避免被滚动容器裁切。

## 6. 空状态

| 位置 | 表现 |
| --- | --- |
| 数据新鲜度 | 「还没有采集到任何日期」，不显示假进度 |
| 名单未解析 | 看板中央引导卡：示例名单格式 + 「去粘贴名单」 |
| 未分组区 | 折叠收起，人数为 0 时整块隐藏 |
| 主播库检索 | 「没有匹配的主播，换个词试试」+ 清空按钮 |
| 趋势图 | 「该主播暂无足够历史数据」文案占位 |
| 展示端组不足 9 组 | 补内置空组占位（时段照排），不出现空洞布局 |
| 历史方案 | 「还没有保存过方案」+ 说明保存入口 |
| 音浪被隐藏 | 两个榜单模块整体消失，页面只有分组名单（不是置灰） |

## 7. 加载与错误状态

- **登录失效（401）**：统一翻译成人话 + 指路「右上角重新登录」，弹回 AuthGate。
- **网络错误**：`failed to fetch` 等 → 「连不上后端接口，请确认服务已启动后重试」。
- **骨架/转圈**：按钮级 loading（导出、刷新转圈）；表格首屏用行骨架；不做全屏 spinner。
- **静默刷新**：展示端每分钟后台刷新，不动 UI；强制刷新才显式 loading。
- **降级链路**：数据库挂 → `/api/health` 报 `db.ok=false` → 首页 warn 条 → 展示页自动用方案快照 + `stale` 徽标，服务不崩、登录不受影响。

## 8. 移动端适配

| 断点 | 行为 |
| --- | --- |
| <640 | 展示页单列卡片 + **吸顶汇总条**；管理端导航可横滑；看板以「卡片菜单」代替拖拽；赛程条横向滚动带渐隐提示 |
| ≥640 | 展示页两列；组内音浪条此时才显示（窄屏不占空间） |
| ≥1024 | 展示页三列 |
| 通用 | `.page` 容器 20/24px 边距随断点；触控目标 ≥40px；日期条/赛程条用 `hide-scrollbar` 或细 rail |

## 9. 可访问性细节（已实现，改版别丢）

- 焦点环统一品牌色 2px + offset（替掉浏览器默认蓝）。
- 导航激活态用 `aria-current='page'` 驱动指示条动画。
- 选中文本用品牌色底（名单页会被大段复制，不用默认灰蓝）。
- 动效统一 0.15–0.2s ease / `cubic-bezier(0.2,0,0,1)`，导航指示条 transform 缩放而非宽度变化。
