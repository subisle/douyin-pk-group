## 1. 设计目标

### 1.1 业务目标

1. 让运营把「名单 + 音浪数据」在 **5 分钟内**变成一份可上架的分组方案。
2. 让主播在手机上 **一眼**看清自己播了多少、排第几、第几组几点开赛。
3. 让数据从导入到公布 **全程可追溯**（批次审计 + 访客留痕 + 上架状态）。

### 1.2 设计目标（可度量）

| 编号 | 目标 | 度量方式 |
| --- | --- | --- |
| DG-01 | 界面克制、无 AI 味 | 全局仅一个品牌色；不使用紫蓝/青色 radial 渐变；阴影不超过三档 |
| DG-02 | 数据可读性优先 | 所有数值 `tabular-nums`；榜单行扫读不换行；大数字一屏可见 |
| DG-03 | 状态诚实 | 任何空/错/降级都有明确文案，不出现假进度、假数据、白屏 |
| DG-04 | 操作不丢失 | 看板有未保存改动时切页必须二次确认；撤销 ≥50 步 |
| DG-05 | 弱网可用 | 展示端零外部请求（单文件 + 系统字体）；降级仍可读 |
| DG-06 | 移动端单手可操作 | 展示端核心操作落在屏幕下半 2/3；触控目标 ≥44px |

### 1.3 设计原则

1. **一个品牌色**：靛蓝只用于导航指示、激活态、焦点环、选中态，不做装饰性渐变。
2. **发丝线而非色块**：用分隔线和留白组织信息，不靠大面积彩色卡片区分区域。
3. **数字是主角**：榜单与看板中，数值的字号、字重、等宽优先级高于装饰。
4. **状态必须显式**：空、加载、错误、降级、冲突各有专属表现，禁止静默失败。
5. **同一事实源**：算法与显隐规则只在后端一处实现，前端不做第二套判断。
6. **零依赖优先**：展示端不引外部字体/图表库；后台不引第三方路由库。

## 2. 设计范围

**本期覆盖**

- 管理后台：登录门 + 8 个页面（数据概况、数据导入、主播管理、抖音号审计、访客日志、族谱、PK 分组、机器人）。
- 对外展示端：单页 4 个视图（每日报告、分组、族谱、我的）+ 登录门 + 读者字段面板。
- 全局设计系统：色彩、字体、间距、圆角、阴影、动效、图标、可访问性。
- 组件规格：约 20 个复用组件的结构与状态。

**本期不做**

- 多角色/多团队权限界面；独立 `/admin/settings` 页（口径暂由机器人页承载）。
- 机器人粉丝侧查询界面；机器人自定义脚本与富媒体回复。
- 移动端 App / 小程序；数据页大屏可视化。

## 3. 用户与任务流

### 3.1 角色

| 角色 | 入口 | 鉴权 | 核心诉求 |
| --- | --- | --- | --- |
| 运营管理员 | `/admin/*` | 管理员口令 → 内存 token（8h 空闲失效） | 录数准、分组快、能微调、能撤销 |
| 主播 | 展示端 `/` | 姓名或手机号 + 密码 | 快速看自己的数据与赛程 |
| 管理员观看账号 | 展示端 `/` | 同上，账号带 `is_admin=1` | 看全站榜单，个人数据为空 |
| 粉丝 / 观众 | 展示端 `/` | 无 | 看榜单和分组 |
| 机器人管理员会话 | QQ / 微信 | 会话绑定 | 不在电脑前也能录数取数 |
| 已绑定主播会话 | QQ / 微信 | 微信扫码绑定（旧流程：手机号 + 绑定码） | 收到日报、暂停推送 |
| 未绑定会话 | QQ / 微信 | — | 静默处理，不暴露名单 |

### 3.2 关键任务流

| 编号 | 任务 | 步骤 | 设计要点 |
| --- | --- | --- | --- |
| TF-01 | 日常录数 | 导入页拖文件 → 预览逐行校验 → 选日期/模式 → 确认入库 → 看批次 | 预览不写库；错误逐行标注；可整日删除重来 |
| TF-02 | 赛前分组 | 粘贴名单 → 解析匹配 → 设口径与组数 → 自动分组 → 拖拽微调 → 看冲突 → 导出/保存 | 未匹配名字标红；约束冲突显式列出；撤销够长 |
| TF-03 | 对外公布 | 看板保存方案 → 上架 → 复制链接发群 | 上架互斥；未上架显示占位不是 404 |
| TF-04 | 主播看数据 | 打开链接 → 登录 → 选日期 → 看榜 → 看分组 | 默认最近业务日；静默刷新；单手可操作 |
| TF-05 | 关系维护 | 族谱搜人定位 → 设师傅/批量导入 → 导出 | 画布平移缩放不丢状态；孤立节点单独成组 |

## 5. 全局设计需求（设计系统）

### 5.1 画布与栅格

| 编号 | 需求 |
| --- | --- |
| DR-VS-01 | 后台画布 `#f4f5f7`，卡片 `#ffffff`，页面顶部允许极轻冷色渐晕，禁止大面积纯白面板 |
| DR-VS-02 | 后台内容区随内容自适应，卡片间距 12px、卡片内边距 16px |

### 5.3 字体与数字排版

| 编号 | 需求 |
| --- | --- |
| DR-VS-09 | 字体栈：`-apple-system, 'PingFang SC', 'Noto Sans SC', 'Microsoft YaHei', sans-serif`；**零外部字体请求** |
| DR-VS-10 | 后台正文 14px / 行高 1.6；表头 11px 大写 + 字距；展示端正文 14px / 行高 1.5 |
| DR-VS-11 | 所有数值使用 `font-variant-numeric: tabular-nums`，拖拽重算时数字不得左右跳动 |
| DR-VS-12 | 大数字（音浪/时长）使用 `.figure` 风格：加粗 + 负字距 + 等宽 |
| DR-VS-13 | 长名字省略号截断，`title` 或长按可看全名，不允许撑破布局 |

### 5.4 间距、圆角、阴影

| 编号 | 需求 |
| --- | --- |
| DR-VS-14 | 圆角仅三档：控件 8 / 卡片 10 / 面板 12；展示端 8 / 12 / 16 / full |
| DR-VS-15 | 阴影仅三档：raise（卡片）`--shadow-card`、float（浮层）`--shadow-pop`、bar（吸顶条）；**禁止随手加第四档** |
| DR-VS-16 | 卡片允许 1px 顶部高光内边，用于区分白色卡片与浅色画布 |
| DR-VS-17 | 间距以 4px 为基准步进（4/8/12/16/24） |

### 5.5 动效

| 编号 | 需求 |
| --- | --- |
| DR-VS-18 | 统一缓动 `150ms cubic-bezier(0.4,0,0.2,1)`；展示端切口径 150ms 淡入 |
| DR-VS-19 | 禁止装饰性循环动画；加载只用按钮级 spinner 或骨架屏 |
| DR-VS-20 | 尊重 `prefers-reduced-motion`，关闭非必要过渡 |

### 5.6 焦点、图标与可访问性

| 编号 | 需求 |
| --- | --- |
| DR-VS-21 | 焦点环统一 `--ring`（品牌色 18% 三像素外环），不允许 `outline: none` 后不给替代 |
| DR-VS-22 | 图标统一 1.6~2px 描边线性风格，尺寸 15/16/18/24；不使用彩色拟物图标 |
| DR-VS-23 | 所有图标按钮必须有 `title` 或 `aria-label`；纯装饰图形 `aria-hidden` |

| DR-VS-26 | 触摸目标 ≥40px（展示端 ≥44px），相邻可点元素间距 ≥8px |

## 6. 组件设计需求

| 编号 | 组件 | 结构 | 状态 | 规格要点 |
| --- | --- | --- | --- | --- |
| DR-C-01 | 按钮 `button` | 文字 / 图标 + 文字 | 默认、hover、active、disabled、loading | 主按钮品牌色实底；次按钮描边；文字按钮只有颜色变化；loading 时禁用重复点击 |
| DR-C-02 | 输入框 `input` | 前置图标 + 输入 + 清空 | 默认、focus、invalid、disabled | 高 36px（后台）/ 38px（展示端）；focus 用 `--ring`；错误在下方给红字原因 |
| DR-C-03 | 选择器 `select` | 标签 + 值 | 默认、open、disabled | 与输入框同高；选项可带 `title` 解释口径 |
| DR-C-04 | 标签页 `tab` | 文字 / 文字 + 计数 | 默认、active、hover、disabled | active 用 2px 品牌色下划线（后台）或实底（展示端）；保留 `aria-current` |
| DR-C-05 | 分段控件 `seg` | 2~3 个互斥段 | 默认、选中 | 用于日/月/年、登录/注册切换；选中实底品牌色 |
| DR-C-06 | 表格 `table` | 表头 + 行 | 默认、hover、选中、空 | 粘性表头；表头 11px 大写字距；行 hover 整行点亮；数值列右对齐等宽 |
| DR-C-07 | 卡片 `card` | 标题 + 内容 + 可选操作 | 默认、hover、可点击 | 圆角 10~12；`--shadow-card`；标题 15px/700 |
| DR-C-08 | KPI 卡 | 标签 + 大数字 + 增减 | 默认、good、warn、点缀色 | 数字等宽大字；语义色只用于增减与状态，不涂满整卡 |
| DR-C-09 | 语义徽标 `badge` | 文字胶囊 | good / warn / bad / info / 金银铜 | soft 底色 + 深色文字；必须提供文字，不靠颜色单独表意 |
| DR-C-10 | 赛程胶囊 `gx-pill` | 组号 + 时段 | 默认、当前、禁用 | 展示端横滑；右侧 44px 渐隐提示「还有组」 |
| DR-C-11 | 弹窗 `dialog` | 标题 + 内容 + 底部操作 | 打开、提交中、错误 | 遮罩 + `--shadow-pop`；Esc/点遮罩取消；提交中禁用关闭 |
| DR-C-12 | 抽屉 `drawer` | 标题 + 表单 + 操作 | 打开、编辑、错误 | 用于主播账号/关系编辑；小屏全宽 |
| DR-C-13 | 开关 `switch` | 标签 + 说明 + iOS 风格拨杆 | on / off / disabled | 左侧两行（标签 + hint），右侧拨杆；改动立即保存并回显「已保存」 |
| DR-C-14 | 日期条 `dates` | 日期胶囊横滑 + 日历按钮 | 默认、选中、今天 | 默认选中最近业务日；超宽横滑；带右侧渐隐 |
| DR-C-15 | 信息条 `alert` | 图标 + 文案 + 可选按钮 | good / warn / bad / info | 用于降级、错误、空态引导；文案必须给下一步动作 |
| DR-C-16 | 骨架屏 `skeleton` | 灰块占位 | — | 仅首屏使用；切换数据时优先「保留旧内容 + 降透明度」 |
| DR-C-17 | 轻提示 `toast` | 圆点 + 文案 | 显示 / 消失 | 4s 自动消失；用于「数据已更新」这类非阻断反馈 |
| DR-C-18 | 看板选手卡 `PlayerCard` | 拖拽握把 + 名字 + 音浪 + 标记 | 默认、拖拽中、锁定、超员、冲突、命中高亮 | 约束/锁定/超员必须有独立标记，不靠颜色单一区分 |
| DR-C-19 | 组卡片 `GroupCard` | 组头（序号 + n/上限 + 时段 + 增补）+ 名单 | 默认、超员、空组 | 超员时组头给出警示；空组给「+ 添加」引导 |
| DR-C-20 | 展示端榜单行 `lb-row` | 名次 + 名字 + 音浪 + 时长 + 状态 | 默认、自己、前三、开播/未播 | 行高 ≥52px；按住复制「名字 + 音浪」；自己的行用品牌色高亮 |

## 7. 页面设计需求

### 7.1 登录门（AuthGate）

**目标**：未登录时唯一入口，一眼知道要口令，输错知道原因。
