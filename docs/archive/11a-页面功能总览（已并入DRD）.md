> **版本**：2026-10-11 ｜ **范围**：`pk-server`（Rust/axum）+ `apps/douyin-web`（React SPA）+ 展示端 `st_page.html`

## 0. 摘要

| 维度 | 结论 |
| --- | --- |
| 产品一句话 | 把「主播名单 + 音浪/时长数据」变成**可微调、可复用、可对外公布**的 PK 分组方案，并把数据榜单推给主播本人看。 |
| 使用角色 | 运营管理员（口令）、主播（姓名/手机号 + 密码）、管理员观看账号、机器人渠道 |
| 三层结构 | ① 管理后台（需口令）② 对外展示端（登录门可开关）③ 机器人（QQ / 微信，内部工具） |
| 技术栈 | 后端 Rust axum + sqlx/MySQL（MariaDB 为唯一事实源）；前端 React + Vite（无路由库）；展示端是服务端内嵌单文件 HTML |
| 算法归属 | 分组算法只在 `pk-core`（Rust）跑一份；浏览器只做展示与拖拽，不发第二份权威实现 |
| 页面总数 | 管理后台 8 个路由 + 登录门；对外展示端 1 个单页 4 个视图（每日报告 / 分组 / 族谱 / 我的） |

## 1. 角色与权限

| 角色 | 入口 | 鉴权方式 | 能做什么 |
| --- | --- | --- | --- |
| **运营管理员** | `/admin/*` | 管理员口令 → 内存 token（8h 空闲失效） | 录数、建账、分组、上架、机器人配置、展示口径开关 |
| **主播（主用户）** | 展示端 `/` | 姓名或手机号 + 密码（密码 4~20 位字母数字） | 看本团每日/每月/每年音浪与时长、看自己的分组与开赛时段、族谱 |
| **管理员观看账号** | 展示端 `/` | 同上，账号带 `is_admin=1` | 榜单/分组/族谱照常看，个人数据为空（`personId=0`） |
| **粉丝 / 观众** | 展示端 `/` | 无（链接即入口） | 看榜单和分组，只读 |
| **机器人管理员会话** | QQ / 微信 | 会话绑定为管理员 | 文本/附件导入、导出、日报、缺数据等全部命令 |
| **已绑定主播会话** | QQ / 微信 | 手机号绑定关系 | 5 条个人命令（日报、个人报告、暂停/开启推送、帮助） |
| **未绑定会话** | QQ / 微信 | — | **静默**，不响应、不暴露名单 |

**权限边界**：一期只有两层——「后台（口令）」与「对外展示（登录门可关）」，不做多角色/多团队权限体系。

## 3. 数据流与算法边界

```
采集 / Excel / 机器人附件
        │
        ▼
  /api/admin/import/*   预览 → 校验 → 幂等提交 → 批次审计
        │
        ▼
  MySQL/MariaDB（唯一事实源）
   daily_metric · monthly_duration · person · account · plan · push_binding
        │                                   │
        │ 只读池                             │ 读写池
        ▼                                   ▼
  /api/public/*（裁剪字段 + 实时音浪）   /api/group/*（arrange / inspect / polish）
        │                                   │
        ▼                                   ▼
  st_page.html（移动端展示）        apps/douyin-web（拖拽看板 → 导出长图/保存方案）
```

- **唯一事实源**：MySQL/MariaDB；SQLite 仅作一次性搬家来源留底。
- **算法单一实现**：自动分组 / 体检 / 微调全走 `pk-core`，前端只发 players、收结果。
- **读写分池 + 只读守卫**：公开接口只读；写操作集中走 `/api/admin/*`。

## 4. 页面设计规格

> 每页统一按 **定位 → 布局 → 模块 → 关键交互 → 空态/降级 → 验收要点** 描述。

### 4.1 登录门（AuthGate）

| 项 | 内容 |
| --- | --- |
| 定位 | 后台未登录时覆盖全部页面的唯一入口 |
| 布局 | 画布正中一张窄卡片：品牌标记 + 标题 + 说明 + 密码框 + 主按钮 + 错误行 |
| 关键交互 | `Enter` 提交；`POST /api/auth/login` 换内存 token；token 8h 空闲失效 |
| 异常处理 | 任意接口收到 401 → 广播事件整站切回登录门，不让用户面对满屏红字 |
| 空态 | 无需密码时按钮置灰（`disabled`），不弹二次提示 |

### 4.2 数据概况 `/admin/data`

| 模块 | 内容 |
| --- | --- |
| 数据概况头 | 标题 + 口径/天数选择（业务日期、近 N 天） |
| KPI 卡组 | 4 张：在册规模、当日音浪、开播数、延迟/连接状态（good / warn 语义色） |
| 音浪 Top N | 榜单表，数值 `tabular-nums` |
| 未播预警 | 连续 ≥2 天未开播名单，橙色告警语义 |
| 团别趋势 | 近 N 天团别音浪趋势图 |
| 日报预览 | 每日报告 SVG 图片预览 |

**验收要点**：无数据时显示「还没有采集到任何日期」+ 去导入按钮；数据库不可用给 warn 横幅而非白屏；切口径不闪空白（保留旧行 + 降透明度）。

### 4.3 数据导入 `/admin/import`

| 模块 | 内容 |
| --- | --- |
| 拖拽区 | 拖入或点击选择 CSV / TSV / 文本文件；不分男女团 |
| 导入类型 | **音浪（按日）** / **时长（按月）** 两类口径 |
| 预览弹窗 | 逐行校验结果 + 日期 / 模式选择；Esc 或点遮罩取消 |
| 确认入库 | 幂等提交（同日重复导入按 merge 口径），返回批次号 |
| 批次列表 | 历史批次、当日状态、整日删除（二次确认） |
| 字段解析 | Excel/TSV/CSV 兜底解析、音浪单位解析、主播档案自动归属团别 |

**验收要点**：入库前后都能一键删除当天数据重来；预览不写库；删除操作必须二次确认；错误逐行标注原因而不是整批失败。

### 4.4 主播管理 `/admin/streamers`

| 模块 | 内容 |
| --- | --- |
| 新建主播 | 名字（必填）+ 团别 + 抖音号（全局唯一）+ 采集 ID |
| 主播台账 | 检索、分页、团队/对外显示/推送标记列 |
| 关系维护 | 师傅设置、徒弟计数、别名、多抖音号（导入合并音浪）、「我的」账号 |
| 导入暂存 | 未建档的导入行，确认后自动补账历史数据 |
| 账号抽屉 | 采集 ID、主号标记（导入回填 `anchor_id` 依据） |
| 行内操作 | 右键/更多：编辑、师傅、抖音号、我的账号、合并、删除 |

**验收要点**：重复主播检测；删除/合并二次确认；空列表给引导卡；检索无结果给「换个词试试」+ 清空按钮。

### 4.5 抖音号审计 `/admin/claims`

| 模块 | 内容 |
| --- | --- |
| 筛选 | 待审核 / 已通过 / 已驳回 / 全部 |
| 申请卡 | 提交人、手机号、抖音号、截图、提交时间、当前状态 |
| 裁决 | 通过 / 驳回 / 撤销；通过后回写主播档案 |

**验收要点**：空态按当前筛选文案区分（「没有待审核的申请」）；裁决后列表即时更新。

### 4.6 访客日志 `/admin/visits`

| 模块 | 内容 |
| --- | --- |
| KPI 卡组 | 总访问、今日独立 IP、放行、拦截 |
| IP 查询 | 输入 IP 现场查询归属地 |
| 日志表 | IP、归属地、放行/拦截、账号、来源、路径、时间 |

**验收要点**：地域门禁的放行与拒绝都要留痕；IP 可点击直接发起查询。

### 4.7 族谱 `/admin/lineage`

| 模块 | 内容 |
| --- | --- |
| 画布 | 师徒树/传承关系图，可展开收起、平移缩放、全屏 |
| 搜索定位 | 搜主播名回车定位到节点 |
| 明细栏 | 选中节点显示资料、师傅、徒弟、别名 |
| 孤立节点 | 无师傅无徒弟的单独分组展示 |
| 关系维护 | 设师傅（搜索弹窗）、批量导入关系（`A➕B`、`A（B）` 两种写法） |
| 导出 | 族谱图片导出 |

### 4.8 PK 分组 `/admin/group`（核心工作台）

自上而下：

| 子模块 | 职责 |
| --- | --- |
| **名单与配置** | 粘贴名单 → 解析；匹配不上的名字标红并可下拉手动绑定；名单自带分数时按名单分数分组 |
| **分组参数** | 音浪口径（total / lastN）、近 N 天数、每组人数、组数、策略（snake / balance / sequential / sequential lastN）、强度位次口径 |
| **工具条** | 自动重排、均衡微调、自动修正、组内按音浪排序、全局找人（命中高亮并滚动到位）、紧凑模式 |
| **撤销/重做** | ≤50 步，`Cmd/Ctrl+Z` / `Cmd/Ctrl+Shift+Z`；输入框聚焦时不劫持 |
| **看板主体** | 组卡片列阵 + 底部「未分组」区；卡片显示名字、音浪、约束/锁定/超员标记；组头显示 `n/上限`、开赛时段、`+` 增补 |
| **拖拽** | 原生指针拖拽 + 触屏握把 + 键盘微调；跨组、组内排序 |
| **约束** | 固定位、互斥、最小间隔、组次等硬约束优先满足；冲突清单明确列出哪条没满足，**不静默失败** |
| **统计栏** | 均衡度（极差）摘要 + 约束冲突清单 |
| **导出** | 750px 宽离屏 `export-stage` 渲染长图 |
| **历史方案** | 保存/载入/删除；显示上架状态；复制分享链接、一键上架/下架（**上架互斥**：新方案上架时其他方案自动下架） |
| **赛制** | 赛事类型（初级/中级小组赛、月终争霸赛、初级/中级晋级赛）与标题配置 |

**验收要点**：拖半小时的看板切页前必须确认；体检/微调结果与前端展示一致（同源算法）；导出长图与实际看板一致。

### 4.9 机器人 `/admin/bots`

| 模块 | 内容 |
| --- | --- |
| QQ 机器人 | AppID / AppSecret 保存、启动/停止、状态 |
| 微信机器人 | 启动/停止、扫码二维码、扫码状态轮询、验证码、iLink token 手工粘贴 |
| 加好友二维码 | 旧流程兜底，展示端「我的」读取 |
| 推送队列 | 入库后延迟推送（默认 30 分钟）、立即推送、失败原因、同业务日去重 |
| 会话管理 | 群聊/私聊会话、管理员绑定、命令限流 |
| 公开站点设置 | 登录门开关、手机号注册开关、页面显隐、分组子页显隐、数据字段开关、徒弟提成设置 |

**公开站点开关清单（后端级，关掉后接口不下发数据）**

- 访问与页面：开启登录门、开放手机号注册、每日报告页、分组页、族谱页
- 分组子页：初级小组赛 / 中级小组赛 / 月终争霸赛 / 初级晋级赛 / 中级晋级赛
- 数据字段：男团链接、女团链接、每日报告、每月数据、每年数据、直播时长、涨跌对照、音浪数值、徒弟提成

### 4.10 对外展示端 `/`

| 模块 | 内容 |
| --- | --- |
| 深色头部（masthead） | 标题 + 状态行；顶部光晕 + 颗粒氛围层；吸顶不动 |
| 主导航 | 每日报告 / 分组 / 族谱 / 我的（被后台关掉的整体消失） |
| 工具条 | 每日/每月/每年三口径、日期条 + 日历、上一期/下一期、搜名字 |
| 每日报告 | 榜单行：名次、名字、音浪、时长、开播状态、涨跌；前三名金银铜徽标 |
| 分组 | 赛事类型子导航 + 赛程时段胶囊 + 组卡片（组内按音浪名次） |
| 族谱 | 公开师徒树 |
| 我的 | 个人数据、同期对照（今日 vs 昨日 / 本月 vs 上月 / 本年 vs 去年同期）、徒弟提成卡、推送绑定 |
| 登录门 | 姓名或手机号 + 密码；可选注册 tab（默认关闭） |
| 读者字段面板 | 读者本地选择显示哪些列，只影响自己，存浏览器本地 |

**验收要点**：后台关掉的字段**接口就不下发**（不是前端藏）；未上架方案显示「分组暂未公布」占位而非 404；数据库不可用降级用方案快照 + `stale` 徽标；每分钟静默刷新带 ±10s 抖动。

## 5. 视觉设计规范

### 5.1 管理端 token（`apps/douyin-web/src/styles.css`）

| 类别 | 取值 |
| --- | --- |

| 氛围 | 顶部光晕（≤6% 透明度）+ SVG 噪点颗粒；名单行发丝分隔 |

### 5.3 通用排版规则

- 字体：系统栈（PingFang SC / Noto Sans SC / Microsoft YaHei 优先），**零外部字体请求**。
- 数字：全部 `tabular-nums`，大数字加负字距，拖拽重算时数值不左右跳。
- 表格：粘性表头、11px 大写字距表头、行 hover 整行点亮。
- 动效：微交互 150ms；展示端口径切换 150ms 淡入。
- 顶栏：`backdrop-filter: blur(12px) saturate(1.6)` + 半透明底。

## 6. 功能需求清单（FR）

> 优先级：P0 必须 / P1 重要 / P2 可延后。状态：已上线 / 后端已实现 / 计划中。

## 7. 状态规范

### 7.1 空态

| 位置 | 表现 |
| --- | --- |
| 数据页无数据 | 「还没有采集到任何日期」+ 去导入按钮 |
| 检索无结果 | 「没有匹配的主播，换个词试试」+ 清空按钮 |
| 主播列表为空 | 引导卡：先建主播或先跑一次导入 |
| 导入历史为空 | 「还没有导入记录」 |
| 机器人未配置 | 渠道卡显示「未配置」+ 配置引导，不显示报错红字 |
| 消息日志为空 | 「机器人还没有收发过消息」 |
| 展示页方案未上架 | 「分组暂未公布」占位，不是 404 |
| 展示端整体关闭 | 「暂未公布」占位页 + 联系方式，不是 404 |

### 7.2 加载态

- 按钮级 loading（导入/导出/刷新转圈），**不做全屏 spinner**。
- 表格首屏骨架；切日期/口径时旧行保持 + 轻微降透明度。
- 展示端每分钟静默刷新不动 UI；连续失败才在头部出现「数据可能不是最新」灰条。
- 机器人登录过程显示进度：等待扫码 → 已扫码 → 已连接。

### 7.3 错误文案

- 一律翻译成人话 + 下一步动作（`reasonOf`）。
- 401 → 指路重新登录；网络错误 → 指路检查服务。
- 分组冲突 → 明确指出哪条约束没满足，不静默失败。

## 8. 响应式断点

| 断点 | 行为 |
| --- | --- |
| `<640`（展示端设计基准） | 展示端单列卡片 + 吸顶汇总条；后台导航横向滑动；表格降级为卡片或关键列横滑；日期条/赛程条横滑带右侧渐隐 |
| `≥640` | 展示端两列；组内音浪条此时才显示 |
| `≥1024` | 展示端三列；后台表格完整列 |
| 通用 | 触控目标 ≥40px（展示端 ≥44px）；iOS 安全区适配；禁用横向溢出；长名字省略号 + 长按看全名 |

## 10. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 展示端弱网可用：单文件内嵌、零外部请求、系统字体；榜单切口径不整页刷新 |
| 可用性 | DB 不可用时展示端降级快照 + stale 徽标，不白屏；后台给横幅提示 |
| 安全 | 口令/token 不进文档；读写分池 + 只读守卫；地域门禁 + 访客留痕；删除类操作二次确认 |
| 一致性 | 算法只有一份（`pk-core`）；展示端字段显隐以后端开关为最终边界 |
| 可维护性 | 无第三方路由库（7~8 条常量路径手写）；展示端为单文件 HTML，零构建 |
| 可观测性 | SSE 事件 + Prometheus/Grafana 指标 + 导入批次审计 |
